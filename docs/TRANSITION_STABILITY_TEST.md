# Starbook Transition Stability Test（v1.7.3 基线 + v1.8.0 秘境之门）

## 目的

专门验证 v1.7.3 修复的三类问题：

1. 前一页视觉残留；
2. 下一页只剩背景、内容晚到；
3. 转场期间其他 scene / block 突然闪现。

## A. 登录 → 魔法书

### 冷启动
1. 清理该站点登录状态或使用未登录浏览器。
2. 打开 Production。
3. 登录。
4. 观察 Gate 退场全过程。

### PASS
- Gate 淡出时魔法书已完整存在；
- 无纯 Ambient 背景空窗；
- 无 Globe / Country / City 等其他 scene 闪现；
- 回忆照片数量增加不会让登录阶段全量等待 Signed URL。

## B. 魔法书 → 地球

1. 登录停在魔法书。
2. 点击宝石。
3. 连续测试 3 次（返回 Book 后再进入）。

### PASS
- Flash 退场时地球已经可见；
- 首次进入不出现「只有夜空背景，地球稍后出现」；
- 第二次进入明显更快；
- 手机不出现长时间冻结。

## C. Globe → Country

优先测试：中国、美国、日本。

### PASS
- 点击后立即有 Portal 光环响应；
- 地图准备阶段 Globe 保持完整，不出现半页残留；
- Portal 展开时国家省级轮廓已经完成；
- 不出现 Country 背景先出现、轮廓后补。

## D. Country → City

选择至少有 3 段 Memory 的城市。

### PASS
- City 首屏卡片结构一次出现；
- 首屏 Cover 不连续从空白逐张突然跳出；
- 未进入视口的缩影继续 lazy load。

## E. City → Player

选择 8 张以上照片的 Memory。

### PASS
- 点击后 Portal 有即时反馈；
- 放映厅出现时 Cover 已准备；
- 前 1–2 张照片已预热；
- 不要求转场前下载全部照片。

## F. 快速返回 / 系统返回

连续执行：

`Book → Globe → Country → City → Player → Back → Back → Forward`

### PASS
- 任意时刻只有一个普通 scene active；
- 无其他页面闪现；
- URL / history state 与画面一致；
- 无永久 `is-busy`、veil、flash、portal backdrop 残留。

## 推荐设备

- iPhone Safari / 微信或系统内置浏览器可作为辅助；
- Android Chrome；
- Windows Chrome/Edge；
- 手机弱网可用 DevTools Fast 3G 进行额外测试。

## G. v1.8.0 秘境之门 / 导航 / 搜索

1. 魔法书点击宝石：烟雾、火星、符文环被吸入宝石 → **门钥匙**光丝旋入、光门盖满 → 光门从中心撕开露出地球。
2. 地球点击国家：点击处出现旋转小符文环 → **幻影显形**圆形揭示，边缘有符文刻度环、金丝与火星。
3. 国家地图点击左上角返回：**熄灯器**光点被吸向中心、熄灭 → 荧光闪烁推开夜色，直接回到**地球**（不再经过大洲目录），地球转向刚才的国家。
4. 地球顶部搜索：「京都」（我们的城市 + 信息卡两个按钮）、「冰岛」（国家）、任意外国城市如「阿尔勒」（在线结果）、英文「paris」；断网时显示「在线城市搜索暂时不可用」，本地结果仍可用。
5. 菜单「七大洲 → 欧洲」：地球转向欧洲。
6. 菜单「动效强度 → 关闭」：所有转场直接切换，不显示门。

### PASS
- 门在任意时刻都不会残留（结束后画面上没有光幕 / 夜色 / 符文环）；
- 目标场景首帧准备好之前门一直盖住画面，等待期间门钥匙光幕上有符文环缓慢转动；
- 手机上转场不明显掉帧；如有，记录机型并改用「柔和」档复测。

## I. v1.8.2 手机真机

1. 清除网站数据后第一次打开、再关闭重开：第二次进入魔法书应明显更快。
2. 魔法书停留 30 秒：封面不闪烁、不出现对角切割、书上方没有亮球；符文环在书前后缓慢环绕。
3. 点宝石：完整看到唤醒 → 封面打开 → 纸页翻动 → 扉页金墨星图画出 → 推进书页 → 暮色光门，期间不冻结；光门盖满后可能短暂静止（地球在后台准备），随后打开露出地球。
4. 在任意页面点右上角最左侧「书本」标识：回到魔法书封面；在魔法书页面该标识不显示。

## L. v1.9.1 照片分组

1. 编辑一段回忆：点「选择」勾选 3 张 →「编为一组」→ 光标自动进入组描述，写一段话；再勾选组外 1 张 + 组内 1 张 →「加入这一组」；勾选组内中间 1 张 →「移出分组」（它应出现在组尾之后）；组首照片点「前移」= 离开组；组外照片点「后移」整组跳过；框头「整组前移」；「拆组」后点「撤销」恢复。
2. 保存后放映，三种风格各看一遍：组内照片出现期间组描述一直浮现，组内不出现单张描述；组外照片照旧逐张显示描述；星图编号显示范围。
3. 手机上重复 1–2：组框内 2 列，组描述输入时页面不缩放；放映文字不压住底部控制条。
4. 世界星图搜索「长沙」：结果下方没有数据来源行。
5. 放映厅选「手动放映」（统计显示「按你的节奏翻页」）→ 放映：扉页停住并出现右侧「› 继续」；每张照片在描述完整显示时停住，描述不消失；点击 / → / 轻触右侧 = 下一张（平滑过渡），← / 轻触左侧 = 上一张；描述没读完就翻页会直接切到下一张；分组照片逐张停靠且组描述一直在；最后一张翻页后进入「终」页。控制条模式按钮切回「自动放映」后不再停住。刷新页面后模式选择保留。

## M. v1.9.2 镜头语言库 / 电影模式 / 拖放编组
1. 一段 10 张以上、描述有长有短（含一句「你说……」）的回忆：银幕风格自动放映，应看到对焦标题、引语、让位诗行、拱窗、画廊低语、竖排、穿越等不同镜头，同一种不连续；组（横屏）为左栏诗行 + 右侧照片溶接。星图、手札各看一遍（主星页、标题卡、便笺、邮戳、胶带 / 回形针）。
2. 自动放映：点放映后（照片多时先显示「正在准备胶片」）从头到尾不停顿；没有进度条；按钮全部退下，鼠标移到画面下方才浮现，移开 1 秒多后退下；开场不闪现按钮。
3. 手动放映：每张照片停在文字完整显示时（标题卡不在消散中）。
4. 编辑器（电脑）：把未编组照片拖进组框（顶边出现「松开 · 加入第 N 组」）；拖组内照片到「移出这一组」区或空白处；拖到另一组照片旁加入那一组；拖组框把手整组移动；每次都能撤销。
5. 手机：三种风格各放一遍，文字不出画面、不压控制条。

## N. v1.10.0 时光之环 / 时光剪影 / 音乐
1. 菜单进入时光长卷：环从终点向起点画出，卡片依次垂下；起点与终点都在页面右侧，终点有一条向右上飞出的线和「TO BE CONTINUED · 未完待续」。
2. 拖动 / 滚轮 / ← →：整环转动并吸附到站点；卡片缓慢自转、轻轻摆动，转到焦点时回到正面；点焦点卡片进入放映，返回后回到时光长卷；点非焦点卡片先转过来。
3. 周年节点：起点「故事的起点」，每满一年一个周年铭牌（含该年回忆数），最后一个周年之后若有回忆还有「第 N 年 · 至今」。点「ANNIVERSARY · 时光剪影」：先准备胶片，然后序幕（年轮表盘）→ 每段回忆一章（剪影显影；胶片带 / 折扇 / 主镜轮换）→ 中途「这一年」数字与足迹 → 尾声（表盘留缺口并延伸出一条线）；空格暂停、Esc 退出、鼠标到底部出现控制。
4. 背景音乐：登录后（用回车登录也算）音乐自动响起并循环；关掉音乐后不再自动播放；手机切到后台再回来自动恢复。
5. 手机重复 1–3：卡片可读、铭牌按钮可点、剪影各版式不出画面。
