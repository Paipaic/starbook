# Starbook v1.10.1 — 时光之环优化 · 日期精确到日 · 纪念日 · 魔法书星空背景

## 1. 版本目标

Owner 需求（2026-10-29，基于 v1.10.0；改动放在新文件夹，原文件夹不动）：
1. 时光长卷太拥挤，很多卡片加载不出来，太密集时卡片一直闪烁；延伸线违和、没有美感。
2. 时光剪影放映时有时残留加载时的文字。
3. 时光长卷不仅能滑动，点击很远的一张时要能直接转过去。
4. 周年节点精确到日，每一段故事的日期也要精确到日。
5. 魔法书页背景是金色的，改成和其他页面一样的星空 + 蓝色。

Owner 决定：纪念日可设置（方案 B）；远处用光珠；延伸线顺环延伸、淡进星空。属于体验修复 + 兼容旧数据的小功能 → 修订号 1.10.1。

## 2. 用户可见变化

- 时光之环：焦点附近才是卡片（电脑左 2 右 1，手机左右各 1），其余是光珠；卡片图片可靠出现、淡入；不再闪烁；延伸线顺环外旋、渐虚，笔尖光点向前书写，「TO BE CONTINUED · 未完待续」沿线排字。
- 点击光珠 / 卡片 / 节点 / 刻度一次转到；鼠标悬停光珠显示日期与标题；从放映返回回到原来那一段。
- 编辑回忆的时间新增「日」；全站日期显示到日；时光长卷标题下「纪念日」徽记，编辑者可设置；周年节点按纪念日每年同一天计算。
- 时光剪影：放映中不再残留「正在准备」文字；日期范围与表盘精确到日。
- 魔法书页背景为星空深蓝。

## 3. Runtime 链路变化

- Scene Runtime / Gate：无变化。`book` 场景的 `world` 由 `book` 改为 `night`（只影响全局氛围层与夜间玻璃样式）。
- `13-overview`：窗口化卡片 + 光珠、鱼眼弧长 `arcs()`、定时缓动 `center()`、命中测试 `hit()`、图片预取 `wantImgs()`、`sb:data` 签名比对 `sigOf()`、离屏静态层缓存。
- `14-year-reel`：按日计算；准备提示的更新在开始放映后停止。
- `05-store` `memoriesOf` 按日排序；`10-city-album` `SB.fmtDate` 显示到日；`11-memory-player` 日期邮戳显示到日。

## 4. 架构 / 扩展契约变化

- 新增 Core 级 `SB.date` 日期工具；新增可选 Book 设置 `settings.anniversary`；`SB.yearReel.open` 的 `from / to` 改为 `YYYY-MM-DD`（兼容 `YYYY-MM`）；`SB.overview` 增加 `hitPoint(i)`。均已写入 `docs/ARCHITECTURE_EXTENSION_CONTRACT.md`。`SB.book` / `SB.magicBook` / `SB.store` 职责不变。

## 15. 用户需要手动操作

无需 SQL。把新文件夹内容复制到仓库文件夹后运行：

```powershell
.\release-current.ps1 -Message "v1.10.1时光之环优化、日期精确到日、纪念日与魔法书星空背景"
```

发布后可在时光长卷「纪念日」徽记里设置纪念日，并在编辑回忆时为同一个月里的回忆补上具体日期。

- `python build.py` + `python tools/check_project.py` → OK。
- 测试数据 32 段回忆（2024-10 至 2026-10，部分只有年月），今天 2026-10-29：
  - 未设纪念日：起点 2024-10-12，一周年 2025-10-12（12 段，2025-10-11 归第一年、2025-10-12 归第二年），二周年 2026-10-12（18 段），「第三年 · 至今」（2 段）。
  - 纪念日 2024-10-15：纪念日之前的 2024-10-12 回忆排在起点之前并计入第一年（13 段）；一周年 2025-10-15、二周年 2026-10-15。
  - 弹窗改为 2024-11-03：节点即时重算为一周年 2025-11-03 + 「第二年 · 至今」。
- 时光之环（电脑 1280×800、手机 390×844）：可见卡片 2–4 张、图片全部加载；真实鼠标点击 / 触屏轻点远处光珠 → 直达第 6 站（途中卡片收起、到达展开）；拖动、节点、起点、返回终点；终点时延伸线文字出现、起点时不出现；无错误。

- 浏览器自动播放策略同 v1.10.0。

- 静止时脚本开销略高于 v1.10.0（笔尖与卡片偏转动画；柔和档 30fps）。
