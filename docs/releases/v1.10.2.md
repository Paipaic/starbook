# Starbook v1.10.2 — 时光剪影进度条与尾声 · 返回原位 · 拖动稳定 · 安卓性能

## 1. 版本目标

Owner 需求（2026-10-29，基于 v1.10.1；改动放在新文件夹，原文件夹不动；所有优化先查资料、写清 prompt 再改）：
1. 周年时光剪影放映过程不能调进度条 → 增加进度条拖动；放映完毕的收尾效果不好看，引申出来的线条违和 → 重新设计。
2. 从时光长卷点进每一段记录，返回时默认回到最新位置 → 返回到点进去的位置。
3. 时光长卷时光轴 / 世界星图地球转动久了会转不动，拖动鼠标出现禁止符号 → 排查并修复。
4. 安卓手机兼容性不足：转场不流畅、放映图片加载卡顿和闪烁 → 优化。

修订号 1.10.2（体验修复 + 小功能，无数据变化）。

## 2. 用户可见变化

- 时光剪影：底部浮现的进度条（章节刻痕、提示、拖动、键盘），精确跳转；放完再按继续从头放；尾声「年轮合拢」（彗星绕圈、回忆星环、外圈新光 = 未完待续）。
- 时光长卷：从回忆返回停在原来那一段。
- 地球 / 时光之环 / 国家地图：长时间拖动不再卡住、不再出现禁止光标；在大洲徽章上按下也能拖动地球。
- 安卓：照片显示尺寸代理图、放映更顺滑、转场与粒子层更轻。

## 16. 测试与验证

- `python build.py` + `python tools/check_project.py` → OK。
- 返回原位（电脑 / 手机 / 安卓仿真）：转到第 8 站 → 打开放映 → `SB.scenes.back()` 与 `history.back()` 两种返回都回到第 8 站。
- 拖动稳定（电脑）：整页文字被选中时拖动时光之环 u 7 → 4.16、选区被清除；抬起落在刻度条上拖动状态正确结束；整页选中时拖动地球 rotY −1.90 → −0.57；在大洲徽章上按下拖动 rotY −0.57 → −1.68。
- 时光剪影：跳到第 3 章 +2.5 秒，舞台只有该章、照片完全显影；鼠标拖动进度条 20% → 55% 后继续播放，`aria-valuetext` 正确；PageDown 跳到下一章；尾声三个时间点截图（彗星 / 星环 / 外圈新光）与「至今」尾声；放完后状态为停止。
- 安卓仿真（Android UA、390×844、dpr 2.6）：`SB.perf.android` 与代理图启用；时光长卷卡片与放映照片均为 `blob:` 代理图（2400×1600 → 1688×1125）；无错误。
- 放映 low 档视觉对比（v1.10.1 vs v1.10.2，同一时间点）：几何计算一致（画内平移改为放大 img 在裁切框内平移）；时间相同的帧差异 < 1%（个别帧因旧版图片加载时序不同不可比）。
- 全链路回归（电脑 high / 手机 low）：魔法书 → 地球 → 国家 → 城市 → 放映 → 返回 → 菜单时光长卷 → 放映 → 返回；无错误。

## 18. 已知问题

- 安卓代理图首次生成需要下载 + 解码 + 缩放 + 编码，首次打开一段回忆的「正在准备胶片」可能比原来长一点（之后放映更顺）；本次只在仿真环境验证，需要真机确认。
- 不支持 Web Animations `getAnimations()` 的旧浏览器上，时光剪影跳转会从该片段开头播放。
- 浏览器自动播放策略同 v1.10.0。
