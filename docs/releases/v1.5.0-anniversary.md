# Starbook v1.5.0-anniversary

## 版本目标
在 2026-10-29 前，把 V1 稳定升级为可实际赠送和长期使用的私密周年纪念版本，同时保留未来多用户、多 Book、多关系、多 Theme、多 Experience 的升级路径。

## 本次完成
- Supabase Anniversary Bridge 前端骨架。
- Auth Gate、Book Context、权限角色。
- V1 JSON Store → Supabase `book_data.payload`。
- Private Storage 上传与 Signed URL。
- 浏览器场景历史基础支持。
- 版本与 Roadmap 文档体系。

## 数据库变化
新增 `books`, `book_members`, `book_data`。具体见 `supabase/migrations/001_anniversary_bridge.sql`。

## UI / UX 变化
- 未登录时显示星屿风格登录门。
- 登录后只有一本 Book 时自动打开，不增加 Library 干扰周年体验。
- 菜单新增账户/退出入口。

## 安全变化
- 不再依赖 GitHub PAT。
- Private Storage + RLS。
- Publishable Key 可在浏览器使用；禁止 Secret Key。

## 性能变化
本阶段主要是后端迁移，尚未进行 Three.js/地图资源全面本地化。

## Bug 修复
- 增加浏览器 `pushState/popstate` 支持，降低返回键直接离开应用的概率。
- 保存使用 `revision` 检测并发覆盖。

## 数据迁移
当前上传的 V1 `site/data/db.json` 为空，因此本工作副本没有实际旧数据需要迁移。若线上仓库另有真实数据，必须先备份再迁移。

## 手动操作
见 `docs/SUPABASE_ANNIVERSARY_SETUP.md`。

## 测试结果
静态构建/语法检查将在本阶段代码完成后记录。Supabase 在线 RLS/Auth/Storage 必须由用户运行 SQL 后做实机验证。

## 已知问题
- Supabase JS 当前从双 CDN 加载，后续可在 10/27 稳定化阶段考虑 vendor 自托管。
- Theme / Experience 只是上下文，尚无动态系统。
- 未实现 Realtime / PWA / Library。

## 待优化项
见 `ROADMAP.md`。

## 下一版本建议
周年交付前只处理 P0 稳定性；10/29 后再正式进入 V2 数据正规化与平台能力。
