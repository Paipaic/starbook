# Starbook v1.8.1 — 柔光分路转场 · 星夜摩洛哥皮 · 菜单精简 · 时光长卷

## 1. 版本目标

Owner 实看 v1.8.0 后的修订：
- 视觉：去除开书汇聚与进入世界星图的过曝；各页面转场不再一致、光线放慢；魔法书材质 / 质感 / 颜色 / 渲染重新设计。
- 布局：菜单只保留「世界星图」与改名后的「回忆总览」（→「时光长卷」），总览改为可拖动、有动态效果的时间轴；「背景音乐」「动效强度」「账户」移出菜单，改为每个页面都有的三枚无文字小标识；城市为空时的页面布局与框图比例重排。
- 全部兼容电脑与手机。调研、实测与设计见 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 10 节。

## 2. 用户可见变化

- 开书：星点汇向宝石时逐渐被「吸收」而不是堆成白斑；冲击光环、光晕、光柱、书页亮度都降低；进入世界星图是暮色中缓缓打开的琥珀光门，不再闪白。
- 转场按路线区分：门钥匙（→ 地球）、幻影显形（→ 国家）、墨金书页（→ 城市 / 时光长卷，新）、冥想盆（→ 放映，新）、熄灯器（返回）；光线流速约为上一版的 55%。
- 魔法书「星夜摩洛哥皮」：午夜靛蓝山羊皮、香槟古金烫金、盲压花边、镶嵌星辰蓝宝石、古金包角，冷色轮廓光与法阵凹陷阴影。
- 左上菜单只有「世界星图」「时光长卷」；右上角三枚标识：音乐（含全站音乐管理）、动效（华丽 / 柔和 / 静止）、账户（退出登录）。
- 「时光长卷」：横向时光河、相片卡、年份视差、景深、年轮刻度条；拖动 / 滚轮 / 触控 / 键盘浏览。
- 空城市：与章节卡同比例的空白章节卡。

## 3. Runtime 链路变化

- Scene Runtime 事务不变。`scenes.go` 门路由：`flash`→`portkey`，`veil`→`nox`，`SB.gate.has(transition)` 为真时（`quill` / `pensieve`）直接使用该门；`portal` 圆形揭示时长由 `SB.gate.portalDuration()` 提供（high 860ms / low 620ms）。`SB.gate` 缺失或未知的 transition 回退到旧 veil。
- 新增 `SB.dock`（`blocks/02y-dock.html`）：`add / open / close / refresh / sync`。音乐面板注册于 `11-memory-player`，账户面板注册于 `02z-account`，动效面板在 `02y-dock` 内。
- 菜单：移除 `book`、`motion`、`continents`、`music`、`account` 菜单项；`overview` 菜单项改名「时光长卷」，使用 `quill` 转场。
- `overview` 场景重写为时光长卷（id 不变），新增 `prepare()` 预签最近 14 张封面。
- `player` 参数可带 `from:'overview'`，`parent` 据此返回时光长卷。
- 调用方：国家 → 城市、搜索卡片 → 城市使用 `quill`；城市 → 放映使用 `pensieve`。

## 4. 架构 / 扩展契约变化

- `SB.dock` 属于 Theme 外壳层（与 `SB.menu` 同级）：只承载设置类入口，不读写业务数据（音乐面板通过既有 `SB.store.saveSettings / uploadAudio` 修改全站音乐，与 v1.8.0 总览页相同）。
- `SB.book` / `SB.magicBook` 分离保持不变。

## 18. 已知问题

- 动效切到「静止」或从「静止」切回时，魔法书符文环数量等少量一次性初始化的效果要刷新页面后才完全对应新档位。
- 时光长卷在回忆非常多（> 200 段）时 DOM 卡片较多；目前只对屏幕附近卡片做景深计算，后续可做虚拟化。
- 放映进行中标识使用 CSS `:has()` 跟随隐藏；不支持 `:has()` 的旧浏览器上标识会常驻但位置仍下移避让。
