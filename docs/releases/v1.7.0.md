# Starbook v1.7.0 — 「光影放映」多图编排放映 · 三种放映风格 · 四季主题 · 编辑器升级

## 1. 版本目标

回应 Owner 对 v1.6.0 放映的反馈（2026-10-26）：

1. 不要「一页一张」：一个画面里可以同时出现多张照片，部分渐渐消失、再渐渐出现新的，转换方式多样且衔接自然；
2. 照片间隔偏长、版式太固定；字幕出现方式没有设计感、字太小；
3. 设置多种放映风格（初版 2–3 种），在添加 / 编辑回忆时选择；
4. （追加）添加内容的界面太简陋，需要升级得更高级、符合整体风格；
5. （追加）放映时可以选择春夏秋冬四个主题，每个主题有对应的色调与视觉效果（如秋有枫叶、冬有雪花）。

新增用户能力（放映风格、季节主题），按语义化版本升次版本号：v1.6.0 → **v1.7.0**。原计划的 v1.6.1 转场、v1.6.2 魔法书 / 地球特效顺延为 v1.7.1、v1.7.2。

调研与候选对比见 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 7 节；提示词见 `prompts/11-memory-player.md`、`prompts/12-memory-editor.md`。

## 2. 用户可见变化

**放映**

- 放映厅新增两行选项：STYLE（银幕 / 星图 / 手札）、SEASON（按月份 / 无 / 春 / 夏 / 秋 / 冬），默认是这段回忆保存的设置，在这里切换只影响本次观看；预计时长随风格变化。
- **银幕**（默认）：电影蒙太奇。宽银幕全幅镜头与双联 / 三联分屏交替；转场有光缝、虹膜、百叶、擦入、光晕溶解、错位竖条；分屏结束时一个面板扩展成全画面，或像两扇门一样向两侧打开露出下一组；分屏中正在讲述的那张照片提亮。短句用竖排大字，长句在下三分之一用大字幕（字距收拢、逐字从模糊到清晰、金线展开）。
- **星图**：星空中 2–3 张烫金相框前后漂浮，带视差和轻微 3D 倾斜；接力更替时旧照片化作星尘、新照片光晕显影，金线把相邻照片连成星座；字幕是大号描金编号 + 逐行升起的文字。
- **手札**：烛光下的皮革书桌，相片一张张落下、回弹、扬起微尘，堆叠在桌上；镜头沿桌面跟随最新的相片；旁白像羽毛笔一样逐字写出，刚写出时有湿墨金光，随后变干；每第三张相片有一枚金色星章。
- **四季**：春 = 樱花瓣翻飞 + 粉桃柔光；夏 = 阳光光束 + 萤火 + 暖金；秋 = 枫叶翻滚 + 琥珀暖调；冬 = 三层雪花 + 银蓝霜边。放映中点控制条上的季节按钮可随时切换，切换时平滑过渡。
- 节奏：每张照片焦点约 3.2–3.6 秒（v1.6.0 为 5.2–16 秒），描述较长时自动多停留到读完。
- 上一张 / 下一张 / 进度条跳到照片焦点时刻，0.5 秒暗场衔接。

**编辑器（添加 / 编辑回忆）**

- 升级为「星屿手稿」：左侧实时海报预览（封面、标题、日期、地点、风格与季节徽章、季节调色与飘落预览、照片数与预计时长）；右侧四章——Ⅰ 故事、Ⅱ 影像（照片卡片网格，直接在卡片上写描述，前移 / 后移 / 设为封面 / 移除，拖拽或点击添加）、Ⅲ 放映（三张带循环示意动画的风格卡片 + 季节选项）、Ⅳ 乐章。手机为单列。

## 3. Runtime 链路变化

无变化：`Auth → SB.user → SB.book.current → SB.store → Scene Runtime`。

新增 Theme 表现层工具（不参与 Runtime Context）：

- `SB.cinema`：风格与季节的公共定义（名称、说明、图标、`styleOf / seasonPref / resolveSeason`），块 11 定义、块 12 使用；
- `SB.player`：在 `play / seek / jump / state` 之外新增 `setStyle / setSeason / stepSeason / estimate`（测试、调试与编辑器预计时长）。

`player` 场景注册方式、参数（`id`、`autoplay`）不变。

## 4. 架构 / 扩展契约变化

无破坏性变化。

- 放映风格、季节都属于 `magic-celestial` Theme 的表现层；`SB.book / SB.store / SB.user` 职责不变，`SB.book` 与 `SB.magicBook` 所有权不变。
- 回忆上的 `style`、`season` 是**Theme 表现偏好**，不是平台能力：其他 Theme 可以忽略这两个字段；没有把某一种风格写死为平台唯一能力。

## 5. Auth / Membership / RLS 变化

无变化。编辑器仍只对有编辑权限的成员开放；上传仍需「编辑者」权限。

## 6. 数据模型 / Migration 变化

**新增两个可选字段，无 migration：**

- `book_data.payload.memories[id].style`：`cinema | constellation | journal`，缺省 → `cinema`；
- `book_data.payload.memories[id].season`：`auto | none | spring | summer | autumn | winter`，缺省 → `auto`（按回忆月份）。

- 只有在编辑器里保存回忆时才写入；旧回忆不需要迁移，按默认值放映。
- `schema_version` 保持 1，不新增 SQL 文件，不运行 SQL。
- 已同步记录到 `docs/DATA_LIFECYCLE.md`「Memory 可选表现字段（v1.7.0）」。

## 15. 用户需要手动操作

只需发布代码，**不需要运行任何 SQL**：

```powershell
.\release-current.ps1 -Message "光影放映：多图编排放映、三种放映风格、四季主题与编辑器升级"
```

发布后：

1. 手机上打开 Production URL，强制刷新一次；
2. 打开任意一段回忆 → 在放映厅切换三种风格、几个季节各放一遍；
3. 进入「编辑」为每段回忆选好放映风格和季节并保存（不选也可以：默认银幕 + 按月份季节）。

## 17. Production 数据影响

- 是否需要重新导入旧数据？**否。**
- 是否需要运行 SQL？**否。**
- 是否会删除 / 覆盖现有数据？**否。** 只在用户编辑并保存某段回忆时为它写入 `style`、`season` 两个可选字段，其余字段与保存逻辑不变。

## 18. 已知问题

- 季节调色的舞台滤镜只在「完整」动效下启用；「柔和」档只叠加颜色层，色调略淡。
- 三联分屏只在横屏、连续三张竖图且描述都较短时出现；竖屏手机上竖图以全幅镜头呈现。
- 照片兴趣点固定在中上部；人物偏在画面边缘的照片，在分屏里可能被裁到一部分（全幅与星图 / 手札不裁切或少裁切）。
- 旧版本前端（缓存未刷新）读到带 `style` / `season` 的回忆时会忽略这两个字段，不影响放映。

## 19. 回滚方案

纯前端改动：revert v1.7.0 的 merge commit 即回到 v1.6.0，Pages 自动重新部署。已保存的 `style` / `season` 字段会被 v1.6.0 忽略，无需数据回滚。
