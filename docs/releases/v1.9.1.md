# Starbook v1.9.1 — 照片分组「同一时刻」 · 自动 / 手动放映 · 搜索面板去掉数据来源行

## 1. 版本目标

Owner 反馈（2026-10-28，基于 v1.9.0）：
1. （批量多选：Owner 确认本地设备已支持，本版不改。）
2. 一段回忆（同一时间 + 地点）里，有几张照片内容相近，希望用**一段文字描述这几张照片**，放映到它们时浮现这段文字；可能分成多个组。
3. 世界星图搜索结果下方的「数据：国家统计局 / 高德（中国区划）· 美国人口普查局 · GeoNames · Open-Meteo · CLDR」不要显示在页面上。
4. / 5. 地球省 / 州轮廓与高清、国家地图视觉升级：规划到周年之后的 v1.10.0 / v1.10.1（见 `ROADMAP.md`）。
6. （追加）放映应该有**自动放映和手动放映**两种。

新增用户能力但范围小、向后兼容 → 修订号 1.9.1。设计见 `prompts/12-memory-editor.md` v1.9.1 节、`prompts/11-memory-player.md` 第 12、13 节、`docs/design/VISUAL_UPGRADE_PLAN.md` 第 14 节。

## 2. 用户可见变化

- 编辑器「影像」：选择照片 →「编为一组」（已有组的成员被选中时为「加入这一组 / 合并为一组」）、「移出分组」；组显示为金色括线框（第 N 组 · k 张 · 整组前移 / 后移 / 拆组 + 组描述）；组内单张描述收起但保留；所有分组操作可撤销。
- 放映：组描述在这组照片出现期间一直浮现，长描述分句依次出现；银幕组内柔和溶接，星图每组独占一页（编号范围「02 — 04」），手札组内照片叠成一小叠。
- 预览统计 / 放映厅：显示「k 组」。
- 放映方式：放映厅「MODE」一行与控制条按钮选择**自动放映 / 手动放映**；手动放映在每张照片描述完整显示时停住（右侧「› 继续」提示），点击 / → / 轻触右侧翻到下一张，← / 轻触左侧回上一张。
- 世界星图搜索：不再显示数据来源行。

## 3. Runtime 链路变化

- Scene Runtime / Gate / 转场：无变化。
- `11-memory-player`：`buildTL()` 先用 `unitsOf()` 切单元，三种导演按单元编排；`SB.player.state` 调试信息增加 `texts`、`groups`。
- `12-memory-editor`：新增 `normalizeGroups / runsOf / snapOf / buildGroup`；照片排序操作遵循分组规则；批量操作注册表新增 `group`、`ungroup`。
- `11-memory-player`（放映方式）：`P.mode`、`holdsOf()` 停靠点（随 `buildTL()` 产出）、时钟 `loop()` 在停靠点停住、`advance()` 翻页（3 倍速 rush / 直接跳转）、`#pl-hold` 提示、`#pl-o-mode` 与 `#pl-mode`；`SB.player` 新增 `next / prev / setMode`。星空闪烁改用不随停靠暂停的氛围时钟。
- `07-globe`：删除搜索结果的 `.src` 行。

## 16. 测试与验证

- `python build.py` + `python tools/check_project.py` → OK。
- 放映（电脑 1280×800 + 手机 390×844，三种风格）：京都回忆 9 张照片，第 2–4 张为一组、第 6–7 张为一组；组描述在组内第一张出现后 0.7 秒浮现，停留到下一单元开始；组内不再显示单张描述；组外照片照旧；星图编号显示「02 — 04」「06 — 07」。
- 编辑器（电脑 + 手机）：编为一组 → 光标进入组描述 → 撤销；选中组外照片 + 组内照片 → 加入这一组；移出中间成员（放到组尾之后）；组首照片前移 = 离开组；组外照片后移整组跳过；整组前移；拆组 → 撤销；保存后 `groups` 与 `g` 写入正确；紧凑视图。
- 手动放映（电脑 + 手机）：扉页与每张照片在描述完整显示时停住；下一张（3 倍速平滑过渡）、描述未读完时直接跳转、上一张、轻触右 / 左分区、→ 键；分组照片停靠时组描述仍在；最后一张后进入「终」页；切回自动放映不再停住；选择保存在本机。
- 搜索面板：输入「长沙」，结果下方不再出现来源行。
- 全链路：无错误。

## 18. 已知问题

- 旧版本（v1.9.0 及以前）打开含分组的回忆时，只会按单张描述放映（新字段被忽略）；发布后所有设备都会加载新版，不影响使用。
- 组描述较长时（> 约 60 字），手札风格会分多段书写，整组放映时间相应变长。
- 手动放映停住时照片画面静止（季节飘落等氛围动画继续）。
- 不能直接拖动整组；用框头「整组前移 / 后移」调整位置。
