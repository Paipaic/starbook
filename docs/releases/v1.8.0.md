# Starbook v1.8.0 — 秘境之门 · 星辉层次 · 地球搜索与导航精简

## 1. 版本目标

按 Owner 要求完成两组升级，并保持 v1.7.3 场景事务与性能分档不被破坏：

- **视觉效果**：「秘境之门」奇幻转场（参考哈利波特系列的幻影显形、门钥匙、熄灯器视效资料）；魔法书与地球的「星辉层次」特效。
- **结构与功能**：删除冗余的大洲国家目录页，国家地图返回直接回到地球；地球正上方新增搜索栏，可搜索任意城市和国家，选中后地球自动快速转到对应位置。

新增用户能力 → 次版本号 1.8.0。调研与设计见 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 8 节。

## 2. 用户可见变化

- **门钥匙**（魔法书 → 地球、菜单 → 地球）：金色光丝沿螺线旋入，暖白蒸汽旋转，光门从书页中心扩大盖满全屏；等待地球时光幕上有缓慢转动的符文环；随后光门从中心撕开，光丝向外甩出。
- **幻影显形**（点击国家 / 城市 / 回忆）：点击处立刻出现旋转的小符文环；圆形揭示的边缘带双圈刻度符文环、螺旋金丝、柔光和飞溅火星。
- **熄灯器 / 荧光闪烁**（返回、菜单跳转）：光点像彗星被吸向中心，夜色收拢，最后一点光熄灭；然后中心亮起一点暖光，推开夜色露出目标页。
- **魔法书**：星云、宝石光溢与旋转光束、绕书一圈的 3D 符文环、升腾烟雾与火星、书页边缘流光；开书时烟雾、火星、符文环被吸入宝石。
- **地球**：海面高光、云雾层、外层光晕、星座线、星盘环、按时间连接我们城市的足迹光弧。
- **导航**：大洲国家目录页删除；国家地图左上角返回 / 面包屑 / 系统返回直接回到地球，地球转向刚才的国家并短暂高亮。大洲徽章、手机底部大洲按钮、菜单「七大洲」改为让地球转向该大洲。
- **搜索栏**：地球标题下方；分组显示「我们的足迹 / 国家与地区 / 城市」；中文、英文均可；选中后地球快速转到目标并亮起光环，下方信息卡提供「打开我们的回忆」「进入 X 地图」。

## 3. Runtime 链路变化

Scene Runtime 事务**不变**：`prepare → cover → activate → await enter → nextPaint → reveal → cleanup`。

- `scenes.go` 的 `flash` / `veil` 分支在 `SB.gate` 存在时调用 `SB.gate.cover(kind)` → `prepareTarget` → `swap` → `SB.gate.reveal(kind)`；`portal` 分支在原 clip-path 圆形揭示的每帧调用 `SB.gate.portalFrame`。
- `SB.gate` 缺失时回退到 v1.7.3 的 veil / flash / 光圈；任何异常调用 `SB.gate.abort()`；bfcache 恢复同样清理。
- reduced 档仍直接切换，不显示门。
- 场景注册：移除 `continent`；`country.parent` 改为 `{id:'globe'}`。
- 新增 `SB.WORLD_CITIES`（离线城市库）、`SB.globe.focus(o)` / `SB.globe.search(q)`、`SB.magicBook.fxSuck(on)`。

- 搜索：「京都」（我们的城市 + 信息卡）、「阿尔勒」（在线）、「冰岛」（国家）、「paris」→ 巴黎、在线服务 500 时显示降级提示；国家返回后场景为 globe 且地球转向该国；手机搜索面板与信息卡布局。

## 18. 已知问题

- 转场总时长比 v1.7.3 略长（门钥匙约 1.4 秒 + 准备时间，熄灯器约 1.1 秒）；转场期间点击会被忽略（与 v1.7.3 相同的 `is-busy` 保护）。
- 在线城市搜索依赖 Open-Meteo，国内网络若无法访问，只显示离线 648 城与国家结果。
- 离线库以世界主要城市为主；小镇需在线搜索。

## 19. 回滚方案

纯前端修改：revert v1.8.0 merge commit 即可恢复 v1.7.3（包括大洲目录页）；Supabase 数据无需回滚。若只想关闭新转场，可临时删除 `blocks/01b-gate.html` 后重新构建（Scene Runtime 自动回退旧转场，但需同步移除 `check_project.py` 的门检查）。
