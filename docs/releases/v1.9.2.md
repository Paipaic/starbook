# Starbook v1.9.2 — 镜头语言库 · 自动放映电影模式 · 拖放编组

## 1. 版本目标

Owner 反馈（2026-10-28，基于 v1.9.1，交付前最后一版）：
1. 编辑器里已添加但未编组的照片，希望用**鼠标拖动放入**已有的编组；组里的照片也能**拖动移出**。
2. 自动放映：从头到尾流畅放完、不卡顿；**不要进度条**，像放电影一样；按钮退下，**鼠标移动到页面下方一定范围才浮现**；衔接丝滑。
3. 放映时文字和照片的呈现太单一：文字的大小 / 样式、出现位置、进场、消失、与照片的互动，照片同样如此，都要丰富设计。

设计见 `prompts/11-memory-player.md` 第 14、15 节、`prompts/12-memory-editor.md` v1.9.2 节、`docs/design/VISUAL_UPGRADE_PLAN.md` 第 15 节。

## 2. 用户可见变化

- **文字样式库**：标题卡（金色大字 + 幕序 + 饰线；放大收拢进场，散成星尘退场）、诗行（侧栏逐行擦出 + 竖金线）、引语（「 」展开、逐字升起）、低语（宽字距小字，焦外到清晰）、逐字点燃字幕、便笺纸条、日期邮戳；文字与照片反向缓慢漂移。
- **照片呈现库**：拱窗、画廊卡纸、侧栏羽化画框；穿越 / 升起 / 显影 / 下沉进退场；**互动**——对焦（标题散去时照片由虚到实、由暗到亮）、让位（照片缩到一侧让出诗行空间）、压暗（引语出现时照片压暗）。
- **银幕**：8 种镜头按照片横竖、描述长短、是否对白自动选择，同一镜头不连续；横屏的组用「故事板」（左栏组描述、右侧照片依次溶接）。
- **星图**：「主星」大相框页（长描述）、短句标题卡、对白引语；相框进场 / 退场轮换；三联页文字下移不再压住中间相框。
- **手札**：相片推入 / 抛落进场；和纸胶带、回形针装饰；每第三段描述写在便笺纸条上；第一张盖日期邮戳；长描述横屏改为更宽的两三行。
- **自动放映**：点放映先「正在准备胶片」预载；没有进度条与计数；放映中所有按钮（含左上菜单 / 返回、右上标识）退下，鼠标进入画面下方 20% 时控制条滑出；开场不闪现按钮。
- **编辑器**：照片拖进组框加入（顶边提示「松开 · 加入第 N 组」）；组内照片拖到「拖到这里 · 移出这一组」区或空白处移出；拖到别组照片旁加入那一组；组框把手整组拖动；均可撤销。

## 3. Runtime 链路变化

- Scene Runtime / Gate / 转场：无变化。
- `11-memory-player`：
  - 新增 `pickShot()`（银幕镜头选择）、`poemCues()`、`GEN / animGen() / inEndOf()`（文字样式库）、`fx()` 新类型 `zoom / rise / develop / sink`、照片 `rack` 互动、画框 `arch / mat / soft`、手札 `deco`、星图 `HERO`。
  - 时钟：华丽档不再限制帧间隔；柔和档 30fps 允许 4ms 误差；文字定格优化（`n.settled`）。
  - `start()`：预载前 12 张后再 `play()`；`data-mode` 控制进度条显示；`zoneH()` 底部浮现；`play()` 不再 `wake()`。
  - `holdsOf()`：只看本段开始的描述，等完整进场、且在退场与本段照片退场之前停住（修正手札 / 星图手动放映停在文字书写中或照片淡出中）。
- `12-memory-editor`：新增 `dragBegin / dropAt / wireGroupDrop / runEnd / gnoOf`，组框 `data-g`、把手、`.ed-gdrop`、`.ed-gout`。

## 16. 测试与验证

- `python build.py` + `python tools/check_project.py` → OK。
- 镜头：12 张照片、描述长短不一（含两句对白、两张无描述、一个 3 张的组）的测试回忆，三种风格 × 电脑（1280×800）/ 手机（390×844）逐张在文字完整显示时截图：银幕依次出现对焦标题、引语、让位诗行（左右交替）、竖排、双联、画廊低语、穿越、故事板组；星图出现标题卡、引语、主星页、编号诗行、三联组页；手札出现日期邮戳、便笺、胶带、回形针、推入 / 抛落。文字均在画面内、不压控制条。
- 电影模式（电脑）：开场按钮不出现；鼠标在画面中部不出现；移到底部控制条与顶部按钮浮现并保持；移回中部约 1.2 秒后退下；进度条与计数不显示。
- 流畅度：12 秒自动放映期间缓冲停顿 0 帧；手机仿真（4× CPU 降速）主线程 291ms/s、脚本 31ms/s（v1.9.1 同场景 312 / 41）。
- 手动放映：每张照片在文字完整显示时停住（标题卡不在消散中、星图照片不在淡出中、手札文字已写完）；翻页 / 上一张 / 轻触分区照旧。
- 编辑器拖放（电脑，真实鼠标拖动）：未编组照片拖进组框 → 加入（组尾）；组内照片拖到「移出」区 → 移出到组后；拖到空白处 → 移出；拖到别组照片右侧 → 加入那一组并插在该位置；拖组框把手到最后一张右侧 → 整组移动；撤销恢复。
- 分组放映、全链路（high / low）：无错误。

## 18. 已知问题

- 镜头选择是确定的（同一段回忆每次放映一样）；改动描述长短或顺序会改变镜头。
- 拖放编组只在电脑（精确指针）上可用；手机仍用「选择 → 加入这一组 / 移出分组」。
- 极慢的设备上单帧超过 80ms 时，时间线按 80ms 推进（画面放慢而不跳帧）。
