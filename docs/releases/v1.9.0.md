# Starbook v1.9.0 — 行政区划搜索 · 影像管理台 · 星盘启封

## 1. 版本目标

Owner 需求（2026-10-28，基于 v1.8.3）：
1. 世界星图很多城市搜不到：以美国、中国为例，要能搜索州与州以下所有郡（县）、省与省以下所有市，并飞转到对应位置；
2. 回忆册照片编辑 / 管理：增加批量添加 / 删除，精心设计、方便管理、便于扩展；
3. 登录加载界面：字体不一致且会突然变化、特效卡顿、界面简陋，重新设计。

新增用户能力 → 次版本号 1.9.0。设计见 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 13 节。

## 2. 用户可见变化

- 搜索：中国 34 省级 / 334 地级 / 2845 县级（县级市、区、县、旗），美国 51 州 / 3144 县；支持简称、州缩写与常见中文简称；新结果组「州省 · 市县」；选中后地球飞转并高亮国家。
- 编辑器「影像管理台」：批量添加（拖入 / 多选、并发上传、进度、失败重试）、选择模式（勾选、Shift 区间、全选 / 反选）、批量操作栏（设为封面、移到最前 / 最后、清空描述、删除）、撤销、电脑拖动排序、紧凑视图。
- 登录加载界面「星盘启封」：多层旋转星盘 + 扫光加载环 + 呼吸宝石，状态行交叉淡入；登录卡片；字体不再中途变化，动画不卡顿。

## 3. Runtime 链路变化

- 启动链（v1.7.3）不变：Auth → Book → Store → `scenes.boot(book)` → 首帧 → 揭开 Gate。新增：`store.ready` 之后状态行显示「正在翻开书页…」；`SB.fx.start()` 从脚本开头移到 `store.ready` 之后（Gate 遮住时不跑背景粒子）。
- Gate：`showLoading / showLogin / showFatal` 切换 `state-loading / state-login / state-error`；`html[data-gate-type]` 一次性字体决策。
- 地球搜索：`buildAdmin()` 懒解析 `SB.ADMIN_DIVISIONS`；`focusTo` 支持 `o.zoom`；信息卡按去后缀名 / 30km 距离匹配我们的城市。
- 编辑器：新增 `SB.editor.photoActions`；上传改为队列 + 并发 2。

## 4. 架构 / 扩展契约变化

## 15. 用户需要手动操作

```powershell
.\release-current.ps1 -Message "v1.9.0行政区划搜索、影像管理台与星盘启封登录界面"
```

- `python build.py` + `python tools/check_project.py` → OK。

- 全链路（high / low）与时光长卷 → 放映 → 返回：无错误。

## 18. 已知问题

- 中国区划基线为 2016 年，之后少数撤并（如 2019 年莱芜并入济南）仍以旧名出现；美国县为 2010 年口径（如阿拉斯加后来的县级调整未包含）。
- 行政区划的中文搜索只覆盖中文名；美国县只有英文名（州有中文名与简称）。
- 首次访问网络较慢时，登录门使用本地宋体（字体一致，但与站内其他页面的思源宋体略有不同）。
