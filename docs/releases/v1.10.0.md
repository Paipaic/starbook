# Starbook v1.10.0 — 时光之环 · 时光剪影 · 背景音乐自动循环

## 1. 版本目标

Owner 需求（2026-10-29，基于 v1.9.2；所有改动放在新文件夹，原文件夹不动）：
1. 时光长卷：直线时光轴改为三维立体的**环**，垂直页面向纵深展开；环不闭合，起点端和终点端很近、都在页面右侧；终点端有额外的线延伸出去（故事还没完）；保留滑动并适配。
2. 记录改为从轴上**悬挂**的 3D 卡片，缓慢转动。
3. 加**时间节点**：以第一条记录日期为起点，每过一年一个节点；节点上有 **anniversary 时光剪影** 按钮，把上一节点到这一节点之间的记录**用新风格重新编排**放映（不是拼接各条记录的放映）。
4. 背景音乐**自动循环播放**。

新增用户能力 → 次版本号 1.10.0（原计划的地球 / 国家地图升级顺延为 v1.11.0 / v1.11.1）。设计见 `prompts/13-overview.md` v1.10.0 节、`prompts/14-year-reel.md`、`prompts/11-memory-player.md` 第 16 节、`docs/design/VISUAL_UPGRADE_PLAN.md` 第 16 节。

## 2. 用户可见变化

- 时光长卷「时光之环」：三维环 + 悬挂 3D 卡片（自转、摆动、正反两面）+ 起点 / 周年 / 至今节点铭牌 + 终点延伸线「TO BE CONTINUED · 未完待续」+ 背景焦点年份；拖动 / 滚轮 / 键盘转动，刻度条保留。

## 18. 已知问题

- 浏览器的自动播放策略因设备而异：首次打开且从未与页面互动时，部分浏览器仍要等第一次点击 / 按键才会响起（之后自动循环）。
- 回忆非常多（手机上超过约 14 段、电脑上超过约 30 段）时，环上卡片会部分重叠（焦点卡片总在最上层）。
- 周年按月份计算（回忆日期精度为月）。
