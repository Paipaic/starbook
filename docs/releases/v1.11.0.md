# Starbook v1.11.0 — 国家星门面板（时空裂隙）

## 1. 版本目标

Owner 需求（2026-10-30 / 2026-11-01，基于 v1.10.2；改动放在新文件夹，原文件夹不动）：
- 删除「世界星图 → 国家」的独立页面；在地球上点击国家时弹出悬浮面板，面板里是该国地图，背景与出现方式要有「穿越时空」的特效，流畅自然、不违和。
- 顾虑：放进悬浮框后城市和「添加」按钮会不会太小、不好操作。
- 2026-10-30 先做了三种风格的可交互原型（星门虫洞 / 光速跃迁 / 时空裂隙）；2026-11-01 Owner 选定**时空裂隙**。

次版本号 1.11.0（导航结构变化：删除一个场景，新增同场景子状态机制；无数据变化）。

## 2. 用户可见变化

- 地球上轻点国家 / 搜索信息卡「进入 X 地图」：从点击处长出竖直光缝 → 向两侧撕开成面板，光边退到两侧淡出；背后地球变暗并转向该国。
- 面板：国名与统计、省级地图（拖动 / 缩放 / 双击复位；去过的省份发金光并标出城市名；点省份筛选城市）、城市栏（点击进入城市，编辑者可改名 / 删除）、底部固定的「＋ 添加城市」（对话框选择所在省份 + 城市名）。
- 电脑：居中大面板，地图左、城市栏右（280px）。手机：底部抽屉，地图在上、城市卡片横向滑动、全宽添加按钮；触控目标均 ≥ 44px。
- 关闭：× / Esc / 点面板外 / 左上返回 / 系统返回键，裂隙逆序合拢。面板 → 城市 → 返回时面板仍展开。
- 魔法路径：世界星图 › 日本 › 京都。

## 3. Runtime 链路变化

- Scene Runtime 新增同场景钩子 `update(params, opts)`（`blocks/00-core.html`）：目标为当前场景且声明了 `update` 时就地切换子状态，不走遮罩 / prepare / swap；仍写浏览器历史（push / replace / fromHistory 规则不变）并派发 `sb:scene`。其他场景切换的事务顺序（`prepare → await enter → nextPaint → reveal`）不变。
- `globe`：`update / prepare(k) / enter(k) / leave`；面板打开时柔和档 / 安卓跳过地球渲染。
- 删除 `country` 场景；`city` 的父级改为 `{id:'globe', params:{k}}`。

## 4. 架构 / 扩展契约变化

新增 Scene `update` 钩子、`globe` 参数 `{k}`、`SB.countryPortal`、`SB.globe.pickAt`（调试），已写入 `docs/ARCHITECTURE_EXTENSION_CONTRACT.md`。面板属于 `world-map` Experience 的视图，不进入 Starbook Core；`SB.book` / `SB.magicBook` / `SB.store` 职责不变。

- `python build.py` + `python tools/check_project.py` → OK。
- 自动化测试 `t1110`（电脑 1280×800 华丽档 / 手机 390×844 柔和档 / 安卓 UA 仿真柔和档）：

  - 日本 47 个都道府县全部绘制并完整落在地图区内（电脑地图区 770×480，手机 366×515）；电脑「添加城市」155×50，手机全宽 366×50。
  - 点京都省份：出现「京都 ×」筛选签，城市栏只剩京都；面板 → 城市（魔法路径「世界星图 › 日本 › 京都」）→ 返回：面板仍展开（同一国家、47 省）→ 再返回：裂隙合拢，`inert` 全部恢复，历史无残留。
  - 电脑：真实鼠标点地球上的日本 → 面板打开；Tab 焦点留在面板内；Esc 关闭。浏览器后退（`history.back`）关闭面板。
