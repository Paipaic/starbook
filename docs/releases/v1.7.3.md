# Starbook v1.7.3 — 场景事务与首帧稳定性修复

## 1. 版本目标

针对 v1.7.2 真实手机测试中仍存在的转场卡顿、旧页残留、目标场景只有背景等待内容、异步页面错闪问题，重构场景生命周期。保持现有视觉设计，不新增主题或视觉特效。

## 2. Runtime 链路变化

Scene Runtime 从“同步 swap + 异步 enter 自行运行”升级为：

`prepare → transition cover → await enter → nextPaint → reveal → cleanup`

新增 `SB.scenes.prefetch(id, params)`；`enter()` / `leave()` 允许 Promise，并由 Scene Manager await。

登录启动链改为：
`Auth → Book → Store JSONB → scenes.boot(book) → first paint → Gate reveal`。

## 3. Auth

Auth / Membership / RLS 规则不变。仅调整登录 Gate 的揭开时机：不再在 `finishAuthenticated()` 内提前隐藏 Gate。

## 4. 数据

数据库 schema、`book_data.payload`、`schema_version` 均不变。Store 启动阶段不再为整本书所有媒体全量签名，只读取 JSONB；媒体 URL 改为场景级按需预取。

## 5. Storage

Private Storage 路径、Bucket、RLS 不变。Signed URL 策略从启动全量 warm 改为 City / Player / Editor 按需批量预取。

## 6. Git

标准链路不变：`release/v1.7.3 → PR → validate-starbook → squash main → GitHub Pages`。

## 7. CI

增加 v1.7.3 Scene Transaction 基线检查：必须存在 `prepareTarget` / `SB.scenes.prefetch` / async scene enter await；禁止 Store 启动全量 `warmUrls`；继续保留旧架构与 `SB.book` 命名保护。

## 8. Agent

新增 5 份逐链路性能 Prompt：
- `prompts/performance/01-login-to-book.md`
- `prompts/performance/02-book-to-globe.md`
- `prompts/performance/03-globe-to-country.md`
- `prompts/performance/04-country-city-deep-scenes.md`
- `prompts/performance/05-scene-runtime-transaction.md`

后续 Agent 修改对应位置前必须先读对应 Prompt。

## 9. 用户需要手动操作

无需 SQL。覆盖代码后本地实测，确认后运行：

```powershell
.\release-current.ps1 -Message "v1.7.3场景事务与首帧稳定性优化"
```

## 10. 测试

重点真机测试：
1. 冷启动登录 → 魔法书；
2. 魔法书 → 地球首次进入；
3. 地球 → 中国/美国/日本；
4. 国家 → 有多段回忆的城市；
5. City → Player → Back 连续往返；
6. 快速返回 / 浏览器返回键。

## 11. Production 数据影响

无 SQL、无数据迁移、无 Storage 搬迁、不会删除或覆盖现有回忆/照片/BGM。

## 12. 回滚

纯前端 Runtime 修改。若 Production 出现回归，revert v1.7.3 merge commit 即可；Supabase 数据无需回滚。
