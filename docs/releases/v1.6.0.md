# Starbook v1.6.0 — Cinematic Player「冥想盆放映厅」

## 1. 版本目标

实现 Owner 需求 4：照片放映不再死板，像放电影一样把照片和文字一张张呈现出来；增加「放映」按钮，自动播放；照片出现、消失、字幕都经过设计。这是视觉升级计划（`docs/design/VISUAL_UPGRADE_PLAN.md`）的第二个版本，属于新增用户能力，因此升次版本号。只改表现层（块 11、块 10）。

设计依据（详见计划第 6 节）：

- 冥想盆（Pensieve）回忆：墨滴入水 → 回忆从涟漪中浮现；
- Ken Burns：缓慢推拉平移，平滑缓动，放大不超过 1.12 避免发虚；
- 溶解转场 1–2 秒，光漏克制使用（每 4 个镜头一次与结尾）；
- Netflix 简体中文字幕规范：每行 ≤16 字、≤2 行、金字塔断行；本项目取每秒 7 字（比上限 9 字更慢，适合抒情文字），每条至少 1.8 秒。

## 2. 用户可见变化

- **放映厅**：点开一段回忆，先看到一张烫金细框的海报、标题、地点、照片张数和预计时长，以及一个带旋转符文环的大「放映」按钮。
- **开场**：熄灯、银幕黑边落下、一滴金色墨滴落入水面泛起涟漪，标题逐字浮现，然后是那段话。
- **镜头**：每张照片自动选择推镜 / 拉镜 / 横摇 / 纵摇；竖图在横屏上以烫金相框悬浮，背后是同一张照片的光场。
- **转场**：第一张从墨渍中揭开；之后为柔和的光尘溶解，偶尔一道暖金光漏。
- **字幕**：照片描述像电影字幕一样在底部逐字浮现，长句按标点自动切成几条依次出现；照片会停留到字幕读完。
- **终章**：暖金闪白后出现「终 · FINIS」、日期地点，以及「再放一遍 / 返回相册」；音乐慢慢变轻，不会突然停止。
- **控制**：移动鼠标或点按屏幕显示控制条（上一张 / 暂停 / 下一张 / 音乐），分段进度条可点击跳转；手机左右滑动切换；键盘 ← → 空格 Esc；切到后台自动暂停。
- 城市相册每张回忆卡片右下角新增金色「放映」按钮，直接开始放映。

## 3. Runtime 链路变化

无变化：沿用 `Auth → SB.user → SB.book.current → SB.store → Scene Runtime`。

放映场景 `player` 的注册方式不变；`enter(params)` 新增可选参数 `autoplay`（来自相册「放映」按钮），旧调用 `{id}` 行为为进入放映厅。

新增表现层工具（不参与 Runtime Context）：

- `SB.audio.duck(level, ms)`：平滑压低 / 恢复音量；
- `SB.player`：`play / seek / jump / state`，仅用于测试与调试。

## 4. 架构 / 扩展契约变化

无变化。放映属于 `magic-celestial` Theme 的表现层；未写入 `SB.book / SB.store / SB.user`；`SB.book` 与 `SB.magicBook` 的所有权不变。

## 18. 已知问题

- iOS Safari 需要用户点击后才能播放音乐：「放映」按钮本身就是这次点击，正常情况下音乐会随放映渐入；若系统静音键打开则无声。
- 照片签名地址超过 5 秒仍未返回时，会继续显示「正在冲洗胶片…」直到照片可用。
- 低性能设备请在菜单中把动效切换为「柔和」：去掉模糊和胶片颗粒，保留镜头运动与淡入淡出。
