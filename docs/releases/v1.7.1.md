# Starbook v1.7.1 — 城市回忆目录页「星屿手稿 · 目录页」

## 1. 版本目标

Owner 2026-10-27 反馈：添加城市后、点进城市查看回忆记录的界面（有「开启回忆」等按钮）还没有优化。本版只升级这一页（块 10），风格与 v1.7.0 回忆编辑器「星屿手稿」保持一致。属于小幅界面优化，升修订号：v1.7.0 → **v1.7.1**。原计划的转场、魔法书 / 地球特效顺延为 v1.7.2 / v1.7.3。

调研见 `docs/design/VISUAL_UPGRADE_PLAN.md` 7.6 节；提示词见 `prompts/10-city-album.md`。

## 2. 用户可见变化

- **页眉**：城市名后方一个缓慢旋转的金色法阵；城市名下一道带四芒星的金线；统计胶囊显示回忆数、照片数和时间跨度；可编辑时有「新的回忆」按钮。
- **时间线**：原来左右交错、两侧大量留白的时间线改为单列金色时间线，从第一段回忆往下读；每段回忆的节点是罗马数字章节徽记（I、II、III…）和竖排年月。
- **章节卡片**：
  - 左侧烫金海报，左上角放映风格徽章、右上角季节徽章，海报带对应季节的调色，悬停时光泽扫过、封面微微推近；
  - 右侧：CHAPTER 编号与日期、标题、照片数、预计放映时长、风格与季节、配乐标记、一段话摘录、最多 5 张照片缩影（多出的显示 +N）；
  - 卡片上直接三个操作：「▶ 放映」（直接开始放映）、「放映厅」、「编辑」；点卡片其他位置进入放映厅。
- **新的一页**：时间线末尾一张「写下第 N 章」虚线金框卡片。
- **空状态**：深色烫金面板 + 描边大写「I」+「这里还没有回忆 · 写下第一章吧」，替代原来的米色羊皮纸。
- **手机**：时间线贴左，海报变成横幅，「放映」按钮独占一行，「放映厅 / 编辑」并排在下一行。

## 15. 用户需要手动操作

只需发布代码，**不需要运行任何 SQL**：

```powershell
.\release-current.ps1 -Message "城市回忆目录页「星屿手稿 · 目录页」升级"
```

## 16. 测试与验证

- `python build.py`、`python tools/check_project.py`：通过。
- 本地 Chromium + 测试替身（不进入仓库）：
  - 桌面 1280×820 与手机 390×844：有 1 段回忆的城市（银幕 · 秋、银幕 · 春、手札 · 冬三种组合）、空城市；页眉、法阵、章节卡片、徽章、缩影、新页卡片、空状态；
  - 交互：「放映」→ 进入放映并自动开始；「放映厅」与点击卡片 → 进入放映厅；「编辑」→ 打开「星屿手稿」编辑器；
  - 无 Console 错误。
- 测试中发现：测试浏览器里卡片的 CSS 入场动画有时停在第一帧，卡片不可见（v1.7.0 及之前的目录页在同一环境下也会出现）。已加保险：入场时间过后移除动画，卡片保证可见；复测通过。

## 18. 已知问题

- 签名地址尚未返回时，海报与缩影先显示深色占位，地址返回后自动重绘。
- 一座城市回忆很多时页面较长；暂不分页（当前每座城市回忆数量有限）。

## 19. 回滚方案
