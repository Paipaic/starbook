# Starbook v1.8.3 — 开书「机关启封」

## 1. 版本目标

Owner 反馈 v1.8.2：开书第一阶段（宝石柔和亮起 + 一圈细光环）内容太少、太淡，希望有机关转动、宝石转动等更丰富的动态。本版只丰富这一阶段，保持 v1.8.1/1.8.2 的曝光与手机性能规则。设计见 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 12 节与 `prompts/04-book-opening.md`。

## 2. 用户可见变化

点宝石后的 1.9 秒「机关启封」：
- 机匣逐级啮合（外圈 → 齿轮环反转 → 三枚小齿轮自转公转 → 内星环），棘轮式「咔哒」步进并逐级加速；
- 宝石旋转加速并两次呼吸缩放；
- 法阵外圆 / 内圆 / 八芒星被金线依次描亮，两颗光珠沿圆环反向奔跑；
- 八颗蓝宝石星绕圈依次闪亮；宝石外圈迸出细小火花；符文环加速并更亮；
- 双重共鸣光环；解锁：包角弹开闪亮、书身轻震、书页切口透光。
随后接扉页金墨星图、星尘与门钥匙（总长约 4.7 秒）。

## 3. Runtime 链路变化

- `SB.magicBook` 新增视觉方法 `awaken(on)`、`unlock()`；`04-book-opening` 第一阶段改为调用它们。Scene Runtime、`SB.book` 不变；开书期间仍不预取地球。
- 魔法书循环：机关启动期间各层按棘轮函数推进；宝石 `#mk-gem` 加入旋转；`#cv-ignite` 描线层；火花画在既有 `#bk-fxc`。

## 16. 测试与验证

- `python build.py` + `python tools/check_project.py` → OK。
- 开书慢动作逐帧（电脑华丽档、手机柔和档）：齿轮逐级转动、宝石旋转、描线与光珠、星辰点亮、解锁均可见；无大面积亮斑、无闪白。
- 手机仿真（4× CPU）：开书前 3.3 秒主线程任务约 160ms/s（v1.8.2 约 135ms/s，v1.8.1 约 708ms/s），无 WebGL 长任务。
- 全链路（high / low）与时光长卷 → 放映 → 返回：无错误、无残留遮罩。
