# Starbook v1.12.2 — 城市真实位置 · 省份中文名 · 忘记密码

## 1. 版本目标

规划文档（仓库外 `星屿之书-后续迭代规划.md`）v1.12.2：
- #3 新加城市的坐标落在省份中心（投影地图的国家甚至落在国家中心），同一个国家的城市在地球上叠成一颗星；
- #4 中美日以外国家的省份名是英文；
- #6a 忘记密码只能去 Supabase 后台处理。

同时清理仓库遗留文件 `blocks/00-config.html.bak`（v1.12.1 发布时脚本提示）。修订号 1.12.2：体验改进，无 schema 变化、无 SQL。

## 2. 用户可见变化

- 「添加城市」城市名下方出现**位置候选**：名称相同的第一条自动打勾，并把「所在地区」切到候选所在的地区；也可以点另一条或「不指定位置」。没有找到时城市放在地区中心，并提示之后可以校准。
- 「编辑城市」显示「位置：大致位置（地区中心）/ 已校准」，「校准位置」打开单独的地点搜索框和候选列表；校准到另一个地区时城市会移过去（同地区重名会提示）。
- 法国、德国、意大利、西班牙、英国、韩国、泰国、越南、澳大利亚等 50 个国家的地区名显示中文。
- 登录页「忘记密码？」→ 发送重设链接；点邮件里的链接回到网站 →「设置新密码」→ 保存后直接进入书。链接失效会提示重新发送。
- 右上角「账户」新增「修改密码」（登录后直接改，不需要邮件）。

## 3. Runtime 链路变化

- `bootRuntime`：创建 Supabase 客户端前读取网址片段（`type=recovery` / `error_code`）；监听 `PASSWORD_RECOVERY`；`getSession` 后清除网址里的令牌，然后按情况进入「设置新密码」/ 登录（带失效提示）/ 正常进入。`finishAuthenticated → 99-boot 揭开 Gate` 的顺序不变。
- Scene Runtime / 国家面板 `update` 钩子 / 转场：无变化。

## 4. 架构 / 扩展契约变化

- 新生成块 `blocks/06-region-zh.html`（`SB.REGION_ZH`），由 `tools/make_region_zh.py` 生成，与 Highcharts map-collection 2.3.3 的分区 key 对应。
- `SB.geo` 新增 `regionPoint / placesLocal / placesOnline / guessRegion`；`SB.user` 新增 `sendReset / setPassword / passwordErrText`。已写入 `docs/ARCHITECTURE_EXTENSION_CONTRACT.md` v1.12.2 节。
- City 字段不变，`lon / lat` 尽量为真实位置。`SB.book` / `SB.magicBook` / `SB.store` 职责不变；不绑定 Theme / Relationship。

## 5. Auth / Membership / RLS 变化

## 18. 已知问题

- 省级地图多为投影坐标，候选所在地区按「自带省份 → 一级行政区名称 → 最近的地区代表点」推断；只有本地结果且离线时，靠近省界的城市可能推断到相邻地区——候选下方会显示推断的地区，用户可以手动改「所在地区」。
- 生成表只覆盖 50 个常去的国家；其他国家仍显示原名（可在脚本里追加国家后重新生成）。
- 默认邮件服务的限制（见第 15 节）。重设链接需在同一浏览器打开（implicit 流程）。

## 19. 回滚方案
