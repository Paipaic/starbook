# Starbook v1.5.2 — Typography System「星文」

## 1. 版本目标

修复 Owner 反馈的“部分文字显示像乱码”，并为 Magic Celestial Theme 建立一套完整、统一、阅读舒适的字体系统。这是视觉升级计划（`docs/design/VISUAL_UPGRADE_PLAN.md`）的第一个版本，只改表现层。

### 乱码根因（本地实测，使用 Google Fonts 仓库原始字体 + Chromium 渲染 v1.5.1）

1. ZCOOL XiaoWei 的「回 圃 圄 圊 崮 徊」字形自身损坏（内外轮廓同向），渲染为实心方块：「回忆总览」→「■忆总览」。
2. ZCOOL XiaoWei 仅覆盖约 7000 字，城市名、照片描述中的罕见字会混入其他字体。
3. `✦ ✎ ✕ ⟲` 不在任何网页字体中，手机回退为 Emoji 或空心方框。
4. Cinzel Decorative 的数字「1」显示为「I」，小字号花体难以辨认。

## 2. 用户可见变化

- 所有中文统一为思源宋体（Noto Serif SC）：标题 600 字重，正文 400，封面书名 900，电影海报式的庄重感。
- 「回忆」「徘徊」等字恢复正常，不再出现方块。
- 拉丁铭文（ORBIS STELLARUM、THE BOOK OF STAR ISLES 等）改为 Cinzel 罗马碑铭体，更清晰。
- 统计数字、日期、时间线、页码改为 Cormorant Garamond 古典数字。
- 编辑、关闭、复位、缩放、排序、星标等符号改为统一风格的金色线性图标。
- 提示条左侧固定一颗发光四芒星。
- 居中大字距标题做了光学居中补偿；标题分隔点「·」不再落在行首。
- 场景结构、交互、动画、数据均不变。

## 3. Runtime 链路变化

无变化：沿用 v1.5.1 的 `Auth → SB.user → SB.book.current → SB.store → Scene Runtime` 链路。

新增的都是 Theme 表现层工具，不参与 Runtime Context：

- `SB.icon(name)`：内联 SVG 图标；
- `SB.type.ready`：字体预热（只加 `sb-fonts-ready` 诊断类，不阻塞启动、不隐藏文字）；
- `SB.fmtTitle(text)`：标题分隔点防断行；
- `SB.ui.button(text, kind, onClick, icon)`：新增可选第四参数，旧调用完全兼容。

Supabase 客户端 `x-client-info` 改为读取 `STARBOOK_CONFIG.version`（仅请求头标识）。

## 15. 用户需要手动操作

只需按常规流程发布代码，**不需要运行任何 SQL**：

```powershell
.\publish.ps1 -Version 1.5.2 -Message "星文字体系统：修复乱码，统一字体与图标"
```

发布后在手机上打开 Production URL，强制刷新一次（或关闭后重新打开主屏幕图标），确认新字体生效。

## 18. 已知问题

- 字体依赖 Google Fonts；若某网络无法访问，回退到系统宋体（Songti SC / STSong），版式与字号不变，但字形略有差异。
- 首次访问时中文字体切片需要下载（约 1–2MB，之后由浏览器缓存）。
- 放映、转场、魔法书/地球特效的视觉升级在后续版本（v1.6.0 / v1.6.1 / v1.6.2）完成。

## 19. 回滚方案

纯前端改动：revert v1.5.2 的 merge commit 即可回到 v1.5.1，Pages 自动重新部署；不涉及任何数据回滚。
