# Starbook v1.5 Anniversary · Phase 3 稳定性测试

本阶段只验证移动端 / 返回导航 / 资源加载可靠性，不测试新的周年内容。

## 1. 桌面端

1. 登录 owner 账号。
2. 打开魔法书进入地球。
3. 连续进入：地球 → 大洲 → 国家 → 地区 → 城市 → 回忆。
4. 连续快速点击浏览器“后退” 2~3 次。
5. 确认画面最终与浏览器历史一致，没有卡在转场中，也没有整页失去点击。
6. 再重新向前进入一次，确认导航仍正常。

## 2. Android Chrome（优先，如果礼物设备是 Android）

1. 竖屏打开页面并登录。
2. 检查登录卡片没有被地址栏 / 底部导航遮挡。
3. 打开魔法书进入地球。
4. 用单指缓慢拖动地球，确认不会因为轻微拖动误进入国家。
5. 用两个手指缩放。
6. 点击大洲按钮与国家。
7. 在国家地图上拖动 / 缩放，确认不会轻微一拖就弹出地区。
8. 连续按系统返回键，确认逐层返回，不会出现 URL 已返回但画面还停在子页面。
9. 锁屏 / 切换 App 10 秒后回来，确认页面仍可继续点击。

## 3. iPhone Safari（如可测试）

1. 竖屏打开。
2. 检查刘海 / Dynamic Island / Home Indicator 不遮挡导航、登录和弹窗。
3. 打开编辑器，点进输入框，让软键盘弹出。
4. 检查弹窗仍能滚动，保存按钮能看到并点击。
5. 关闭键盘，确认场景没有高度错乱。
6. 测试地球拖动、国家地图拖动、浏览器返回。

## 4. 弱网 / CDN 恢复

可选：浏览器 DevTools → Network → Slow 3G。

1. 刷新页面。
2. Supabase 或 Three.js 加载失败时，不应永久停在 Loading。
3. 脚本会在单个源超时后尝试备用 CDN。
4. 网络恢复后刷新，应能正常进入。

## 5. 通过标准

- 没有透明遮罩阻止点击。
- 地球拖拽、双指缩放正常。
- 地图拖动后不会大量误触。
- 连续返回不会造成画面与 history 不同步。
- 页面从后台恢复后不会残留 `is-busy` 导致全站无法点击。
- 390px 左右宽度下导航与弹窗没有明显溢出。

发现问题时，请同时提供：

1. 设备 / 浏览器。
2. 从哪个场景进入哪个场景。
3. 实际表现。
4. F12 Console 红色错误（如果有）。
