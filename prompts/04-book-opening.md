# 块 04 · 开书动画 提示词（v1.8.2「星尘启封」，约 3.7 秒 + 门钥匙）

> v1.8.2 Owner 真机反馈：光点汇聚落下时曝光仍然严重，要求**重新设计**开书特效；手机上开书动画完全看不见，卡几秒直接跳转。
> 依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 11 节。设计原则：**不汇聚、不叠加、不闪白**；光只从宝石与书页「流出」，并且很快变淡；所有重计算（WebGL）都推迟到门钥匙盖满之后。

1. **唤醒**（0–0.9s）：机匣齿轮平缓加速（3–4 倍），宝石柔和充能（光晕不超过书宽 78%），烫金纹饰亮起；0.5s 时一圈**细**光环（1.5px 香槟金线 + 12px 柔光）从宝石扩散一次。全局粒子不汇聚。
2. **启封**（0.9–3.0s）：封面以书脊为轴打开；书页柔光亮起（中心 alpha ≤ 0.45）；纸页依次轻轻翻起又落下（手机 2 张、电脑 3 张）；纸页落下后，**扉页上用金墨自己画出一幅星图**（两组星座 + 一条连线，线条依次描出 1.5s、星点依次弹出，扉页原纹章淡到 28%）；同时少量星尘从书页四周与上缘**向上**缓缓飘散（正常混合，单颗 alpha ≤ 0.6，电脑 ≤ 70 颗、手机 ≤ 26 颗），符文环收拢淡出。
3. **入页**（3.0–3.7s）：镜头推进书页中心（电脑放大到 1.9 倍、手机 1.5 倍）并淡出；门钥匙「暮色漩涡」从书页中心打开（见 `prompts/00-gate.md`）。
- 动画中禁止重复触发；回到首页时书恢复合上（星图、星尘清空）。
- 静止档：只做直接切换。
- 性能：开书期间不得调用 `SB.scenes.prefetch('globe')`（会同步创建 WebGL，冻结动画）；星图为静态 SVG + CSS 描线动画；星尘画在已有的 `#bk-fxc` 画布上。

## v1.8.3「机关启封」——丰富第一阶段（Owner：宝石亮起 + 一圈光环太淡，想要机关转动、宝石转动等更丰富的动态）

> 依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 12 节。仍遵守 v1.8.1/1.8.2 的曝光与手机规则：不汇聚、不闪白、亮色只是细线与小光点（正常混合）；只用 transform / opacity 与少量 stroke 描线动画；开书期间不创建 WebGL。

第一阶段从 0.9s 扩展为 **1.9s 的「机关启动」**，之后接原来的启封与入页（总长约 4.7 秒）：

| 时间 | 动作 |
|---|---|
| 0.00s | **机关逐级啮合**：外圈刻度环 → 齿轮环（反转）→ 三枚小齿轮（自转 + 公转）→ 内星环，每隔 0.16s 启动一层；转动是**棘轮式**——每秒 4 次「咔哒」步进（快进 → 短暂停顿），速度在 1.2s 内逐级加快到 6–8 倍。 |
| 0.00s | **能量沿烫金流动**：法阵的外圆、内圆与八芒星被一条香槟金细线依次描亮（外 → 内，每条 0.6s），两颗光珠沿外圆、内圆相反方向循环奔跑。 |
| 0.10s | **宝石转动**：宝石从静止开始旋转，1.4s 内加速到每秒约 1 圈，并做两次轻微「呼吸」缩放（1 → 1.12 → 1），折射光斑随之转动；宝石光晕适度扩大。 |
| 0.50s | **星辰依次点亮**：法阵八个顶点的蓝宝石星绕圈依次闪亮（每颗 0.1s 间隔，放大 1.5 倍后回落）。 |
| 0.30–1.70s | **机关火花**：宝石外圈沿切线方向迸出细小金色火花（正常混合、alpha ≤ 0.6，电脑 ≈ 30/s，手机 ≈ 12/s），向外飞散、很快熄灭。 |
| 0.30–1.80s | **符文环加速**：书外的符文环转速逐渐提高到 6 倍并更亮；启封时向外扩散淡出（不向中心收拢）。 |
| 1.20s | **双重共鸣**：两圈细光环（间隔 0.18s）从宝石扩散。 |
| 1.50s | **解锁**：四角古金包角同时向外微微弹开（3–4px）并闪一下；书身「咔」地轻震一次（±2px，0.35s）；书页切口透出一线暖光（局部柔光）。 |
| 1.90s → | 进入原「启封」阶段：封面打开、纸页翻动、扉页金墨星图、星尘上飘；机关在开书时逐渐慢下来。 |

手机（柔和档）：机关与宝石转动、描线、星辰依次点亮、解锁都保留；火花数量减半以下；描线只描外圆与八芒星两条；不加滤镜阴影。
