# 块 04 · 开书动画 提示词（v1.8.2「星尘启封」，约 3.7 秒 + 门钥匙）

> v1.8.2 Owner 真机反馈：光点汇聚落下时曝光仍然严重，要求**重新设计**开书特效；手机上开书动画完全看不见，卡几秒直接跳转。
> 依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 11 节。设计原则：**不汇聚、不叠加、不闪白**；光只从宝石与书页「流出」，并且很快变淡；所有重计算（WebGL）都推迟到门钥匙盖满之后。

1. **唤醒**（0–0.9s）：机匣齿轮平缓加速（3–4 倍），宝石柔和充能（光晕不超过书宽 78%），烫金纹饰亮起；0.5s 时一圈**细**光环（1.5px 香槟金线 + 12px 柔光）从宝石扩散一次。全局粒子不汇聚。
2. **启封**（0.9–3.0s）：封面以书脊为轴打开；书页柔光亮起（中心 alpha ≤ 0.45）；纸页依次轻轻翻起又落下（手机 2 张、电脑 3 张）；纸页落下后，**扉页上用金墨自己画出一幅星图**（两组星座 + 一条连线，线条依次描出 1.5s、星点依次弹出，扉页原纹章淡到 28%）；同时少量星尘从书页四周与上缘**向上**缓缓飘散（正常混合，单颗 alpha ≤ 0.6，电脑 ≤ 70 颗、手机 ≤ 26 颗），符文环收拢淡出。
3. **入页**（3.0–3.7s）：镜头推进书页中心（电脑放大到 1.9 倍、手机 1.5 倍）并淡出；门钥匙「暮色漩涡」从书页中心打开（见 `prompts/00-gate.md`）。
- 动画中禁止重复触发；回到首页时书恢复合上（星图、星尘清空）。
- 静止档：只做直接切换。
- 性能：开书期间不得调用 `SB.scenes.prefetch('globe')`（会同步创建 WebGL，冻结动画）；星图为静态 SVG + CSS 描线动画；星尘画在已有的 `#bk-fxc` 画布上。
