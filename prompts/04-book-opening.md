# 块 04 · 开书动画 提示词（v1.8.1：柔光版，总长约 4.8 秒 + 门钥匙）

> v1.8.1 Owner 反馈：开书时星星汇聚落下曝光太强、刺眼。依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 10.2 节的逐帧实测：粒子全部用叠加混合并被吸向同一点，宝石处亮度失控。

1. 0–1.0s 启动：机匣各层平滑加速；宝石充能（光晕**适度**扩大，不超过书宽 70%）；烫金图案由内向外依次点亮；全局粒子切到 gather 向宝石旋涡汇聚——**粒子越接近宝石越透明**（距离 < 160px 开始淡出，< 40px 完全消失，被宝石「吸收」），汇聚中的粒子整体亮度上限 0.6；魔法书烟雾、火星、符文环同样在接近宝石时淡出。
2. 1.0–1.4s 共鸣：宝石放出两圈**细**冲击光环（2px 香槟金线 + 柔光 12px，alpha ≤ 0.7）；镜头推近 4%；粒子轻微 burst。
3. 1.4–3.2s 翻开：封面以书脊为轴打开到 −165°；书页中央的放射光柱亮度降低（alpha ≤ 0.35），三张纸页依次轻轻翻起又落下；扉页文字浮现。
4. 3.2–4.8s 入界：粒子切到 warp（放射状光线，**中心 120px 内不绘制**，线条 alpha ≤ 0.35）；镜头推进书页中心（放大并淡出）；进入「门钥匙 · 暮色漩涡」（见 `prompts/00-gate.md`），光门起点为书页中心——**不再闪白**。
- 动画中禁止重复触发；回到首页时书恢复合上。
- 静止档：只做宝石发光 + 直接切换。
