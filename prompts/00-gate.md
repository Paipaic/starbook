# 块 01b · 「秘境之门」奇幻转场 提示词（v1.8.1：柔光 · 分路 · 放慢）

> 依据：`docs/design/VISUAL_UPGRADE_PLAN.md` 第 8.2 / 8.3 节（v1.8.0 调研）与第 10.2 / 10.3 节（v1.8.1 Owner 反馈与逐帧实测）。
> 必须遵守 `prompts/performance/05-scene-runtime-transaction.md` 与 `docs/PERFORMANCE_GUIDE.md`：不改变 `prepare → cover → activate → await enter → nextPaint → reveal → cleanup` 事务，只替换 cover / reveal 的视觉。

## 1. 设计原则

- **每条路线一种魔法**：用户在不同层级之间移动时，能从转场感觉到「去了哪里」——进入世界、走进国家、翻开城市、沉入回忆、回到上一层各不相同。
- **舒适优先**：光线流速慢、曲线柔（easeInOutSine / easeOutQuint），不使用急加速；单次转场 1.4–2.0 秒，不让人等得焦躁，也不晃眼。
- **曝光规则（硬性）**：
  1. 全屏遮罩只能是深色（夜色 `#07091c`、暮色 `#151632 → #2a2140`）；亮色只能是**局部光源**（光门、光丝、涟漪、星点）。
  2. 任何一帧里，亮度 > 85% 的近白色区域不得超过约 20% 屏幕面积；叠加（`lighter`）层的单层 alpha ≤ 0.55。
  3. 汇聚到同一点的粒子必须随距离淡出（被「吸收」），不得堆积成白斑。
- **光有来源**：光门 / 涟漪 / 书页光边都从具体的点或边发出。

## 2. 结构

- 块 `blocks/01b-gate.html`：全屏画布 `#sb-magic-gate`（z-index 53，低于菜单 60），只在转场期间显示和绘制；结束后清空并停止 RAF。
- `SB.gate`：
  - `kinds`：`['portkey','nox','quill','pensieve']`；`has(kind)`；
  - `cover(kind, {x, y})` / `reveal(kind, {x, y})` → Promise（每个都有 `setTimeout` 兜底，后台标签页不会卡住事务）；
  - `portalStart(x, y)` / `portalFrame(x, y, r, k)` / `portalEnd()`：幻影显形装饰；
  - `abort()`、`active`。
- `00-core` 的 `scenes.go`：`transition` 为 `flash`（=portkey）、`veil`（=nox）或 `SB.gate.has(transition)` 时走门；`portal` 走 clip-path 圆形揭示 + 装饰；`SB.gate` 缺失时回退 v1.7.3 视觉。

## 4. 五种门

### 4.1 门钥匙 · 暮色漩涡（`portkey`）
- cover（high 950ms / low 700ms）：
  - 18–28 条（low 12）**琥珀色细光带**沿对数螺线**缓慢**旋入（总旋转约 1.2 圈），线宽 0.9–1.6px，alpha ≤ 0.5，尾部渐隐；
  - 4–6 团淡琥珀蒸汽缓慢顺时针转动（alpha ≤ 0.28）；
  - 暮色从四周向中心收拢（深靛蓝 → 紫褐），中心保留一个**柔和的琥珀光门**（半径约短边 18%，峰值亮度约 60%），最后整个画面为暮色 + 中心光门。
- 等待（目标场景准备中）：暮色上一圈细符文环缓慢转动（alpha 0.35），光门轻轻呼吸。
- reveal（high 1050ms / low 750ms）：光门从中心向外缓缓扩张成柔边（不规则羽化），新场景在门内出现；光带反向缓慢飘散淡出；不出现全屏亮色。
- 起点：开书时用书页中心；菜单时用屏幕中心。

### 4.2 幻影显形（`portal`，装饰 Scene Runtime 的圆形揭示）
- 准备：点击处 18px 细符文环缓慢旋转 + 柔光呼吸。
- 揭示（Scene Runtime 时长 high 860ms / low 620ms，easeOutQuint）：边缘一圈细符文刻度环（转速为 v1.8.0 的一半）、3 条螺旋细金丝、外沿柔光（alpha ≤ 0.3）、少量缓慢飘出的火星（high 40/s、low 18/s）。

### 4.3 墨金书页（`quill`，新）
- cover（high 700ms / low 520ms）：一张深色「书页」从右侧翻入：前缘是一条微弯的曲线（像纸页弯曲），沿前缘有一道窄的香槟金书边光（宽 2–3px + 18px 柔光）与少量缓慢飘落的金尘；页面本身为深靛蓝夜色，带极淡的纸纹（低频噪声）与页面阴影（前缘外侧 40px 渐暗）。
- reveal（high 800ms / low 580ms）：书页继续向左翻出，前缘光带随之移动，露出新场景；金尘留在原处慢慢淡出。
- 手机上同样水平方向；方向固定为「向左翻页」（前进）。

### 4.4 冥想盆（`pensieve`，新）
- cover（high 850ms / low 600ms）：
  - 从点击处向外一圈圈**银蓝涟漪**（3–5 圈，间隔 160ms，线宽 1.2px，alpha ≤ 0.45，随扩散变淡）；
  - 深蓝「水面」从点击处以柔边圆扩张覆盖全屏（颜色 `#0b1530 → #050914`）；
  - 4–6 缕银色记忆丝（贝塞尔细线 + 柔光，alpha ≤ 0.4）绕中心**缓慢**旋转，整体画面有很轻的左右倾斜摆动（±1.5°，2.4s 周期，只作用于丝缕层）。
- reveal（high 950ms / low 680ms）：从点击处向外「浮出」：柔边圆形区域逐渐透明露出放映厅，边缘一圈银蓝涟漪，丝缕向外散开淡出。

### 4.5 熄灯器（`nox`）
- cover（high 720ms / low 520ms）：16–28 颗（low 12）光点像彗星一样**缓慢**沿弧线被吸向中心（尾迹 alpha ≤ 0.45），越接近中心越淡；夜色由外向内收拢；中心一点柔光最后熄灭。
- 等待：夜色中心一粒极弱的余烬呼吸。
- reveal（high 820ms / low 600ms）：中心「荧光闪烁」亮起一点暖光（半径 ≤ 短边 10%，alpha ≤ 0.7），光向外推开夜色（羽化扩张），光点缓慢散开淡出。

## 5. 性能与无障碍
- DPR：high ≤ 1.5，low 1；low 粒子数约为 high 的一半，去掉宽光晕描边。
- 每帧只用 `drawImage` 精灵、少量 path 与 1–2 个渐变；门钥匙 / 熄灯器 / 书页 / 冥想盆的底色用纯色或单个径向渐变。
- reduced：Scene Runtime 直接切换，不显示门。
- 画布 `pointer-events:none`、`aria-hidden`；转场期间 `body.is-busy` 阻止交互；任何异常 `abort()` 清理。
