# 块 00-runtime · 登录 / 启动门「星盘启封」提示词（v1.9.0）

> Owner 反馈（2026-10-28）：进入首页加载登录页时，加载特效与字体不一致、特效卡顿、字体会突然变化，界面简陋。依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 13.4 节。Auth / Book / Store 启动链路（v1.7.3：Gate 等 Book 首帧后才揭开）**不变**，只重做 Gate 的视觉与字体策略。

## 1. 根因与原则
- **字体突然变化**：标题、正文、拉丁铭文依赖网络字体（Noto Serif SC / Cinzel），字体到达前浏览器先用系统字体，到达后整体替换（FOUT）。
  → **字体决策只做一次**：Gate 出现时文字先隐藏（只显示无文字的星盘图形）；最多等 2.2 秒——字体到齐就用网络字体，没到齐就**整段启动过程固定使用本地宋体回退栈**，之后即使网络字体到达也不在 Gate 上替换。文字统一淡入。
- **特效卡顿**：旧转圈图标带 `drop-shadow` 滤镜、卡片使用 `backdrop-filter`，在启动阶段主线程繁忙时每帧都要重绘。
  → **只用合成器动画**：所有动画都是 `transform` / `opacity`（浏览器合成器线程执行，主线程忙时也不卡）；旋转的元素不带滤镜，光晕是静止的径向渐变层；卡片不用背景模糊。

## 2. 版式
- 全屏深靛夜空：底层渐变 + 两层星点（一层缓慢自转 240s，一层若干颗星交替闪烁）。
- **中央星盘**（电脑 260px / 手机 216px）：
  1. 外环：细圆 + 72 刻度 + 四枚菱形，60s 一圈；
  2. 星点环：6 颗小星沿圆周，24s 反向；
  3. 虚线环：40s 反向；
  4. 八芒星：90s；
  5. **扫光环**（加载指示）：一道金色锥形扫光沿圆环循环（2.6s 一圈，遮罩成环形，旋转的是整层）；
  6. 中心琥珀宝石：缓慢呼吸缩放（3.2s），下方静止的柔光晕做透明度呼吸。
- 星盘下方：拉丁铭文 LIBER INSULARUM STELLARUM、标题「星屿之书」、状态行（「正在连接星海…」「正在翻开书页…」「正在点亮星图…」，切换时交叉淡入）。
- **登录态**：星盘缩小（0.62）并上移，下方淡入登录卡片（邮箱、密码、开启星屿、提示）；卡片为深色玻璃质感（实色渐变，不用背景模糊），金色细边 + 四角花饰。
- **错误态**：状态行变为错误标题与说明，下方按钮「重新连接」「返回登录」。
- **揭开**：星盘放大 1.25 并淡出，整体淡出（520ms / 柔和档 320ms）。

## 3. 性能与无障碍
- 动画层都设置 `will-change: transform`，数量 ≤ 8；柔和档去掉闪烁星层与扫光环的第二道光；静止档（reduced）不旋转。
- 文字隐藏期间屏幕阅读器仍可读取（只改 opacity）；状态行 `aria-live="polite"`。
- 不依赖任何网络资源即可完整显示星盘。
