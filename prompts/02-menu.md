## 左上角按钮「星屿之书」（不变）
- 全站常驻；发光宝石图标 + 标题字，深色半透明药丸、金色细边、宝石 4 秒呼吸一次。
- 有上一层时，按钮右边出现圆形「返回」光球。

## 悬浮菜单
- 展开动画：从按钮处缩放 + 模糊变清晰，0.45 秒。
- 顶部：拉丁铭文 + 「魔法路径」面包屑。
- **只有两项**（符文图标 + 名称 + 一句说明）：
  1. **世界星图** —— 旋转地球，搜索任意城市，寻找我们的足迹；
  2. **时光长卷**（原「回忆总览」）—— 说明为「N 段回忆 · 从 YYYY 到 YYYY」，无回忆时「我们的故事从这里开始」。
- 底部状态行（书名 · 可以编辑 / 只读浏览）保留。
- 菜单项通过 `SB.menu.add` 注册；「合上魔法书」「七大洲」「背景音乐」「动效强度」「账户」不再注册为菜单项。

## 右上角工具标识 `SB.dock`（新块 `blocks/02y-dock.html`）
- 位置：每个场景右上角（`top: 14px + safe-area`，`right: 14px + safe-area`），三枚 36px 圆形玻璃标识横排，间距 6px；手机同尺寸（触控区用 44px 透明外扩）。
- 外观：与左上按钮同材质（深色半透明 + 金色细边），图标 18px 香槟金描线；无文字，`aria-label` + `title` 提示；默认 0.82 不透明度，悬停 1.0 并带柔光。
- **v1.8.2 回到魔法书**：标识组最左侧一枚「书本」标识（与右侧三枚之间多留 6px 间隔），点击直接用熄灯器转场回到魔法书封面，不展开面板；在魔法书页面上自动隐藏。手机（≤ 480px）标识缩为 32px（触控区仍 ≥ 44px），保证与左上「星屿之书」按钮、返回光球同排不重叠。
- 三枚设置标识：
  1. **音乐**（音符）：播放中图标旁有 3 根极细的跳动音柱。面板：开 / 关开关、当前曲名；可编辑者：全站背景音乐「试听 / 换一首 / 上传音乐 / 移除」（从原总览页迁移）。
  2. **动效**（魔杖星芒）：面板为三档单选卡片 **华丽 / 柔和 / 静止**，每档一句说明（华丽：完整粒子与光效；柔和：手机与旧电脑推荐；静止：几乎无动画，直接切换）；系统开启「减少动态效果」时只显示说明。
  3. **账户**（人像）：面板显示邮箱、角色徽章、当前书名、「退出登录」按钮（二次确认）。未登录时整组标识隐藏。
- 面板：在标识下方右对齐展开，宽 min(320px, 100vw − 24px)，玻璃面板 + 金色细边 + 四角花饰；展开 0.35 秒缩放淡入；一次只开一个；点外部 / Esc / 切换场景时收起；左上菜单打开时收起面板（反之亦然）。
- 放映进行中：标识跟随放映控件「醒来」显示、静止时隐藏，并下移到「编辑 / 退出放映」按钮下方，不遮挡画面。
- 层级：z-index 60（与导航同层，低于弹窗 80 与提示 90）。
