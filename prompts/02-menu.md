# 块 02 · 导航按钮与悬浮菜单 提示词

## 左上角按钮「星屿之书」
- 全站唯一常驻按钮；发光宝石图标 + 标题字，深色半透明药丸、金色细边、宝石 4 秒呼吸一次。
- 进入书里之后，按钮右边出现一颗圆形「返回」光球（箭头符文），点它回到上一层；首页不显示。

## 悬浮菜单（羊皮纸卷轴质感）
- 展开动画：从按钮处缩放 + 模糊变清晰 + 金边描绘，0.45 秒。
- 顶部：拉丁铭文 + 「魔法路径」面包屑（当前所在位置的每一级都可点）。
- 菜单项（符文图标 + 名称 + 一句说明）：
  1. 合上魔法书（回到封面）
  2. 世界星图（地球仪）
  3. 七大洲（展开二级：亚洲、欧洲、北美洲、南美洲、非洲、大洋洲、南极洲）
  4. 回忆总览
  5. 背景音乐：播放/暂停（显示当前曲名）
  6. 动效强度：柔和 / 华丽
- 点外部或 Esc 收起；手机上宽度 = 屏宽 − 28px，超出高度可滚动。
- 各块通过 `SB.menu.add/update` 注册菜单项。
