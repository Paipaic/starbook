# 块 12 · 回忆编辑器 提示词

- 以魔法卷轴弹窗打开（手机为全屏抽屉）。
- 字段：
  - 标题（必填，占位提示「2026 年 5 月 · 宽窄巷子的雨」）
  - 时间（年-月选择）
  - 一段话（可选，显示在放映扉页）
  - 照片：点击或拖拽上传多张（手机可直接从相册选），显示上传进度；
    每张照片一行：缩略图 + 描述输入框 + 上移/下移/设为封面/删除。
  - 专属背景音乐：无 / 使用全站音乐 / 上传一首（显示曲名，可试听）。
- 底部：取消、保存（金色主按钮）；编辑已有回忆时还有「删除这段回忆」（需二次确认）。
- 保存时校验：标题不能为空、至少一张照片；上传中不能保存。
- 照片在浏览器里先压缩再上传；HEIC 等浏览器读不了的格式给出明确提示。
