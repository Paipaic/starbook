# 块 12 · 回忆编辑器「星屿手稿」提示词（v1.7.0 升级）

> 依据：`docs/design/VISUAL_UPGRADE_PLAN.md` 7.5 节。保存 / 上传 / 文件清理逻辑与 v1.6.0 完全相同，只升级界面，并新增 `style`、`season` 两个可选字段。

## 版式
- 仍使用 `SB.ui.dialog` 卷轴弹窗（手机为底部全屏抽屉），弹窗加宽到 min(1040px, 100%)。
- 桌面两列：
  - 左列 260px（滚动时吸顶）：**实时海报预览**——4:5 烫金细框，封面照片（没有照片时显示四芒星 + COVER），底部渐变上是日期（Cormorant）、标题（思源宋体 600，金色光晕，最多三行）、地点；左上角风格徽章（图标 + CINEMA / CONSTELLATION / JOURNAL），右上角季节徽章；海报上叠加所选季节的调色与少量 CSS 飘落元素（花瓣 / 光点 / 枫叶 / 雪）。下面一行「N 张照片 · 约 X 秒」（用 `SB.player.estimate` 按所选风格计算）。
  - 右列四章，每章标题：圆形罗马数字徽记（Cinzel）+ 中文章名（思源宋体 600 金色）+ 拉丁副标（Cinzel 小字、大字距）+ 向右渐隐的金线。
- 手机：单列；海报缩成 96px 缩略图 + 标题 + 统计的横条。

## 四章
- **Ⅰ 故事 · THE TALE**：标题（大号衬线输入，20px）；时间（年 / 月两个圆角下拉，金色小箭头，Cormorant 数字）；一段话（多行，右下角字数「n / 300」）。
- **Ⅱ 影像 · THE IMAGES**：照片**卡片网格**（每张 ≥168px）：4:3 缩略图，左上大号序号「01」，封面卡片金色描边 + 「★ 封面」徽章；悬停（触屏常显）时底部浮出操作：前移 / 设为封面 / 移除 / 后移；卡片下方直接是描述输入框（「这张照片的故事…」）。最后一格是「添加照片」虚线金框（圆形 + 号），点击选择或把照片拖到整个章节区域。上传中的卡片显示进度文字。
- **Ⅲ 放映 · THE SCREENING**：
  - 三张风格卡片（单选）：上方 16:10 循环示意动画（纯 CSS：银幕 = 两面板擦入 + 光缝 + 字幕线；星图 = 三个小相框接力浮现并连线；手札 = 相片落下堆叠 + 墨线写出），下方风格名 + 英文 + 一句说明；选中时金色描边与右上角金点。
  - 季节主题（单选胶囊）：按月份 · X / 无 / 春 / 夏 / 秋 / 冬，带线性图标；下方一句说明当前季节效果，并提示观看时也可以在放映控制条里临时切换。
- **Ⅳ 乐章 · THE SCORE**：无 / 使用全站音乐 / 上传一首（显示曲名，可试听），放在一个细边框面板里。

## 保存
- 底部：删除这段回忆（编辑已有回忆时，二次确认）、取消、保存（金色主按钮）。
- 校验：标题不能为空、至少一张照片、上传中不能保存。
- 保存的数据在原有字段之外增加 `style`（cinema / constellation / journal）与 `season`（auto / none / spring / summer / autumn / winter）。
- 照片在浏览器里先压缩再上传；HEIC 等浏览器读不了的格式给出明确提示；未使用的上传文件在关闭时清理（逻辑不变）。

## v1.9.0「影像管理台」——照片批量添加 / 选择 / 删除 / 排序（Owner：照片编辑管理要方便，需要批量添加 / 删除，并便于后续扩展）

> 依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 13 节（相册类产品的批量管理模式：iOS 照片 / Google Photos 的「选择」模式、Lightroom 的胶片条与密度切换、通用的批量操作栏 + 撤销）。数据结构不变：仍然只改 `st.slides` 与 `st.cover`，保存 / 文件清理逻辑不变。

### 1. 章节工具栏（Ⅱ 影像 标题下方，一行）
- 左：统计「N 张照片」（选择模式下为「已选 k / N」）。
- 右（从左到右）：**批量添加**（金色主按钮，`multiple` 选择器）· **选择**（进入 / 退出选择模式）· **视图切换**（「卡片」带描述 / 「紧凑」小图网格，记住偏好到 localStorage `sb-ed-density`）。
- 上传进行中：工具栏下出现一条细进度条「正在上传 3 / 12 · 已完成 9」，失败的张数用红金色小字提示「2 张未能上传」并可「重试」。

### 2. 批量添加
- 选择器与整个「影像」章节都支持拖入多张照片；电脑上拖入时整章出现金色虚线高亮与「松开即可添加 N 张照片」。
- 上传**并发 2 张**（手机 / 柔和档也是 2），按选择顺序排队；每张卡片显示自己的进度；全部完成后提示「已添加 N 张照片」。
- 失败的照片保留在「失败」列表里，可一键重试（重新排队）或忽略。

### 3. 选择模式
- 进入后每张卡片左上角出现圆形勾选框，卡片其余操作按钮隐藏；点卡片任意位置 = 勾选 / 取消；电脑上 Shift + 点击 = 连续区间选择；Esc 退出选择模式。
- 工具栏变为：全选 · 反选 · 取消选择 · 完成。
- **底部批量操作栏**（吸附在影像章节底部，选中 ≥ 1 张时出现）：已选数量 + 操作按钮：
  - 设为封面（仅选中 1 张时可用）
  - 移到最前 / 移到最后（保持选中照片之间的相对顺序）
  - 清空描述
  - 删除（红金色，二次确认「从这段回忆中移除 k 张照片？」）
- 删除后出现 6 秒的「已移除 k 张 · 撤销」条，撤销可原位恢复（照片文件在保存时才清理，撤销不需要重新上传）。

### 4. 排序
- 普通模式：电脑上可直接**拖动卡片**调整顺序（拖动时卡片半透明，目标位置左侧出现金色插入线）；手机保留「前移 / 后移」按钮。
- 选择模式：用「移到最前 / 移到最后」批量调整。

### 5. 可扩展
- 批量操作以注册表形式定义：`SB.editor.photoActions = [{id, label, icon, danger?, when(sel, st), run(sel, ctx)}]`；以后增加「旋转」「移动到其他回忆」「设为放映开场」等，只需追加一项，不改界面代码。
- `ctx` 提供 `st`、`render()`、`confirm(text)`、`toast(text)`、`undo(snapshot)`。

### 6. 手机
- 工具栏按钮缩为图标 + 短字；批量操作栏横向可滚动，固定在抽屉底部之上；紧凑视图 3 列。
- 勾选框触控区 ≥ 44px。

## v1.9.1 · 照片分组「同一时刻」

> Owner 反馈（2026-10-28）：一段回忆（同一时间 + 地点）里，常有几张照片拍的是同一个瞬间，希望**用一段文字描述这几张照片**，放映到它们时浮现这段文字；一段回忆里可能有多个这样的组。

### 1. 数据（可选字段，向后兼容，不需要 SQL）
- 照片：`slides[k].g = 组 id`（字符串，如 `g4k2m9x`）；没有 `g` 的照片不属于任何组。
- 回忆：`groups = [{id, text}]`，只保存仍有成员的组；没有组时不写这个字段。
- 组成员在 `slides` 里**必须连续**（编辑器负责维持）；放映器把连续且 `g` 相同的照片视为一组。旧回忆没有这两个字段，行为完全不变。
- 组内照片原有的单张描述**保留在数据里不删除**；组描述不为空时放映只显示组描述，组描述为空时仍按单张描述放映（拆组后单张描述原样恢复）。

### 2. 网格里的组
- 一组照片显示为横跨整行的**金色括线框**（`.ed-group`）：左侧一道竖向金色括号线；框头「第 N 组 · k 张」+ 整组前移 / 整组后移 / 拆组；框头下方是**组描述输入框**（最多 300 字，带字数），占位文字说明「放映到这几张照片时会一直浮现」。
- 框内照片使用与外面相同的卡片（序号、封面星标、单张操作），但**不显示单张描述输入框**（收起）。
- 紧凑视图里组框同样存在，组描述输入框保留（它是这组唯一的文字）。

### 3. 创建与调整
- 选择模式下批量操作栏新增（注册在 `SB.editor.photoActions` 最前）：
  - **编为一组**（选中 ≥ 2 张）：选中的照片按原有顺序聚到第一张所在位置，组成新组，并把光标放进新组的描述框。
  - 选中的照片里已经有某组的成员时，按钮变为 **加入这一组** / **合并为一组**：沿用第一组的 id 和描述（第一组描述为空时取下一个非空描述），被涉及的组的全部成员 + 选中的照片聚在一起。
  - **移出分组**（选中的照片里有组成员时）：移出的照片放到原组的最后一张之后，组保持连续。
  - 以上操作都可撤销（6 秒撤销条）。
- 单张卡片的前移 / 后移：组内照片在组内移动；已是组的第一张 / 最后一张时再向外移 = **离开这一组**（位置不变，紧贴组外）。不在组里的照片遇到相邻的组时**整组跳过**，不会被误吸进组里。
- 电脑拖动排序：照片放到哪张卡片旁边，就加入那张卡片所在的组（目标不在组里则离开原组）。
- 框头「整组前移 / 后移」：整组与前 / 后一个单元（一张照片或另一组）交换位置。
- 「拆组」：成员全部恢复为普通照片（单张描述恢复显示），可撤销。
- 任何排序操作之后执行一次 `normalize`：同一组被拆成多段时，成员最多的一段保留组身份，其余照片离开该组；没有成员的组在保存时丢弃。

### 4. 其它
- 预览海报下的统计：「12 张照片 · 2 组 · 约 1 分 20 秒」。
- 批量操作注册表的 `label` 可以是函数 `label(sel, st)`（用于「编为一组 / 加入这一组 / 合并为一组」）。
- 手机：组框内 2 列卡片；框头按钮只显示图标；组描述输入框字号 ≥ 16px（iOS 不缩放）。

## v1.9.2 · 拖动加入 / 移出编组（电脑）
> Owner：已经添加到编辑界面、但还没编组的照片，希望用鼠标**拖进**已有的组；组里的照片也可以**拖出**来移出分组。

- 拖动任意照片卡片时，所有组框进入「可放入」状态（虚线金边）；鼠标进入某个组框（不在某张卡片上）时，组框高亮并显示「松开 · 加入第 N 组」，松开后照片放到该组**最后**。放在组内某张卡片左 / 右侧 = 加入该组并插在那个位置（金色插入线）。
- 拖动组内照片时，组框下方出现一条虚线区「拖到这里 · 移出这一组」；放到该区、组框外的任意卡片旁或网格空白处 = 离开该组（放在组外卡片旁时插到那个位置；放到移出区 / 空白处时放到组的后面）。
- 拖动组框头部（✥ 把手）可以整组移动：放到其他卡片 / 组框的左右侧。
- 每次拖放后显示一条可撤销的提示（「已加入第 2 组」「已移出第 1 组」）。
- 手机不支持拖放，仍使用「选择 → 加入这一组 / 移出分组」。
