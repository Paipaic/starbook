# 星屿之书 · 总体架构提示词（第二版）

## 项目定位
私密在线网页「星屿之书」，一对恋人的超级记忆容器。整站是一本发光的魔法书：
翻开 → 3D 星光地球仪 → 大洲 → 国家目录 → 国家地图（每个省/州一颗星） → 城市回忆目录 → 照片放映 + BGM。
两人在电脑和手机上都能查看、添加、修改，数据实时同步。初始数据为空。

## 全局视觉基调（所有块遵守）
- 奇幻童话、温暖魔法金光。魔法书和地球都要有光芒和粒子环绕。
- 主色：琥珀金（光）、深墨褐（书的世界）、夜空靛蓝（星图世界）。金色永远是"被点亮/去过"的意思。
- 单一深色主题（刻意选择）。
- 字体（v1.5.2 起）：中文标题与正文统一思源宋体（Noto Serif SC），拉丁铭文 Cinzel，数字 Cormorant Garamond，详见 `prompts/00-typography.md`。ZCOOL XiaoWei 与 Cinzel Decorative 因字形损坏/数字难辨已移除。
- 减少留白：每个场景都有铺满的背景光、粒子、雾霭或法阵；内容尽量撑满视口。
- 动效：慢、柔、连贯。只在开书、进入新层级这种关键时刻加速爆发。
- 流畅：动画只改 transform / opacity；粒子用 canvas 一次性绘制；按设备自动降级；页面隐藏时暂停；尊重"减少动态效果"。
- 手机：悬停交互改为点按；所有面板宽度适配 390px 屏宽。

## 导航
- 首页（魔法书封面）只有左上角一个「星屿之书」按钮，所有功能从它的悬浮菜单进入。
- 进入书里之后，按钮右侧多出一颗小小的「返回」光球，菜单顶部显示当前的魔法路径（世界星图 › 亚洲 › 中国 › 四川 › 成都），每一级都能点回去。
- 每次场景切换都有衔接动画：
  - 开书进入地球：金光闪白 + 镜头从远处飞向地球；
  - 进入下一层：光尘汇聚成幕再散开（veil）；
  - 打开回忆放映：画面像书页一样向内卷入暗场（portal）。

## 代码组织
- `prompts/`：每块一份提示词（先写提示词再写代码）。
- `blocks/`：每块一个 HTML 片段（自己的 `<style>` + 结构 + `<script>`）。
- `index.html`：总文件，由 `build.py` 按文件名顺序拼接，每块被
  `<!-- ████ BLOCK xx START ████ -->` 和 `<!-- ████ BLOCK xx END ████ -->` 包住。
- `tools/make_world.py`：从地图数据生成块 06。
- 块之间通过全局 `window.SB` 通信：
  `SB.scenes` 场景、`SB.fx` 粒子、`SB.menu` 菜单、`SB.ui` 弹窗表单、
  `SB.store` 云端数据、`SB.geo` 地理工具、`SB.audio` 背景音乐。

## 数据模型（云端数据库）
- `cities/{id}`：`{country, countryName, region, regionName, name, lon, lat, createdAt}`
  - `country` 为地图键（如 `cn`），`region` 为省级地图键（如 `cn-sc`）。
- `memories/{id}`：`{cityId, title, date:"2026-05", note, cover:{id}, slides:[{id, w, h, caption}], bgm:{id,name}|null, createdAt, updatedAt}`
- `settings/main`：`{bgm:{id,name}|null}`
- 照片和音乐存在网页自带的文件存储里，数据库只保存文件 id，显示地址为 `/_blob/{id}`。
