# 块 05 · 存储（GitHub 版）提示词

## 目标
网页放在 GitHub Pages 上，任何浏览器直接打开就能看，不需要登录任何服务。
城市、回忆、设置和照片、音乐都存在同一个 GitHub 仓库里。
只有输入了「编辑钥匙」（GitHub 访问令牌）的设备可以添加和修改；没有钥匙的人只能浏览。

## 仓库里的文件
- `index.html`：网页本身。
- `data/db.json`：全部文字数据 `{cities:{id:{…}}, memories:{id:{…}}, settings:{…}}`。
- `media/<id>.jpg`：压缩后的照片；`media/<id>.mp3|m4a`：音乐（原文件直接上传，无需转码）。

## 读取
- 浏览者：读取网站自己的 `data/db.json`（加时间戳避免缓存）。
- 有钥匙的设备：通过 GitHub 接口读取最新版本（不受网站缓存影响）。
- 页面可见时每 60 秒检查一次更新，另一台设备的修改会自动出现。

## 写入
- 一次「保存」只产生一个提交：把新照片、删掉的照片和新的 `db.json` 放进同一个提交。
- 照片在选择后就先上传成"草稿文件"（不触发网站重建），保存回忆时才正式提交；取消编辑时草稿自动作废。
- 提交前总是先读最新的 `db.json` 再修改，两人同时编辑也不会互相覆盖；遇到冲突自动重试。
- 刚上传的照片在本机立刻可见；其他设备要等网站重新发布（约 1 分钟）后可见。

## 编辑钥匙
- 菜单里的「编辑钥匙」：输入 GitHub 令牌（只授权这个仓库的内容读写），以及仓库名（自动识别，一般不用改）。
- 钥匙只保存在这台设备的浏览器里，不会写进网页代码或仓库。
- 输入后立即验证，显示"已连接，可以编辑"或具体的错误原因。

## 兼容
- 在 Claude 上打开时继续使用 Claude 云端存储；本地打开文件时用本机临时存储。
