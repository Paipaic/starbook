# 块 09 · 国家星门面板（v1.11.0 起；原「国家地图」场景）提示词

> v1.11.0 Owner 需求：删除「世界星图 → 国家」的独立页面。在地球上点击某个国家时，在地球之上展开一个**悬浮面板**，面板内是该国家的地图、城市列表与「添加城市」按钮；面板展开需要「穿越时空」的特效，流畅自然、不违和。Owner 在三种原型（星门虫洞 / 光速跃迁 / 时空裂隙）中选定 **时空裂隙**。
>
> 参考资料：WAI-ARIA APG Dialog (Modal) Pattern（初始焦点、Tab 循环、Esc 关闭、关闭后焦点归还、`role="dialog"` + `aria-modal` + `aria-labelledby`）；Chromium 合成 clip-path 动画（`inset()` 关键帧动画可由合成器驱动，逐帧 JS 改 `clip-path` 每帧都要重绘）；移动端底部抽屉「系统返回键先关闭抽屉」的通行做法（打开时 `pushState`，返回时由 `popstate` 关闭）。

## 1. 结构与职责
- 面板是**世界星图场景（`globe`）内的一个状态**，不是新场景：`SB.scenes.go('globe', {k:'jp'}, {x, y})` 打开，`SB.scenes.go('globe', {})` 关闭。由 `SB.scenes` 的 `update(params, opts)` 钩子就地处理（见 `prompts/00-core.md` v1.11.0），不走全屏转场，也不重建地球。
- 块 09 只提供组件 `SB.countryPortal`：
  - `open(k, {x, y, instant})`：从 (x, y) 撕开裂隙展开；`instant` = 在遮罩后面直接呈现（返回 / 深链 / 历史前进）。
  - `close({instant})` → Promise：裂隙合拢。
  - `isOpen`、`key`、`busy`（展开 / 合拢动画中）。
  - 面板 DOM 在脚本执行时移入 `globe` 场景元素内（位于地球画布之上），不新增 `.sb-scene`。
- 块 07（地球）负责：点击国家 / 信息卡「进入 X 地图」→ `SB.scenes.go('globe', {k}, {x, y})`；`update / enter / leave` 中调用组件；面板打开时地球飞转到该国并保持高亮；柔和档在面板完全展开后停止重绘地球（画面保留最后一帧）。
- 关闭路径全部走 `SB.scenes.back()`（× 按钮、Esc、点面板外、左上返回光球、系统返回键）：
  - 当前历史条目是从「无面板的地球」打开面板而来 → `history.back()`（系统返回键与按钮行为一致，不留假历史）；
  - 否则（深链 / 从城市返回）→ `go('globe', {}, {replaceHistory:true})`。
- 魔法路径：`世界星图 › 日本 › 京都`。`globe.title({k})` 返回国名，`globe.parent({k})` 返回 `{id:'globe', params:{}}`；城市页的父级为 `{id:'globe', params:{k:city.country}}`，从城市返回时地球场景在遮罩后直接呈现已展开的面板。
- 旧的 `country` 场景与 `#country` 锚点删除；旧历史条目里的 `country` 状态被忽略（与 v1.8.0 删除 `continent` 的处理一致）。

## 2. 面板布局
- 电脑（> 720px）：居中悬浮，`min(1120px, 92vw) × min(780px, 86vh)`，圆角 22px，金色细边 + 深色外框 + 远距离柔光。
  - 头部：小字 `TERRA · JP`（Cinzel）、国名大字、统计「点亮 X / Y 个都道府县 · N 座城市 · M 段回忆」；右上角 44px 关闭按钮。
  - 主体两栏：左侧地图（自适应填满），右侧 280px 城市栏。
  - 底部：操作提示（小字）+ 金色主按钮「＋ 添加城市」（高 50px，只对可编辑成员显示）。
- 手机（≤ 720px）：从底部升起的抽屉，高 `calc(100% - 64px - safe-top)`（顶部留出左上导航按钮），上圆角。
  - 主体上下排列：地图在上；城市卡片在下方横向滑动（scroll-snap），卡片最小宽 140px、高 ≥ 56px；
  - 「添加城市」为全宽大按钮，贴底，含安全区；单手可点。
- 城市在面板里不会变小：城市卡片、按钮、关闭按钮的触控尺寸都 ≥ 44px。

## 3. 地图（沿用 v1.10 的省级地图与数据，不改数据格式）
- 数据：`SB.geo.loadCountryMap(k)`（缓存）；无省级地图的国家用整国轮廓（单一地区，`key = k + '-all'`）。
- 坐标拟合到**地图容器**（不是窗口），四周留 16px。
- 省份：深夜蓝填充、金色细边；去过的省份淡金；悬停 / 选中的省份提亮。
- 每个省份中心一颗四芒星：去过 = 明亮金色带光晕；没去过 = 暗淡小星。去过的省份旁边标出城市名（多座时「京都 等 3 城」）。星和字随缩放保持屏幕尺寸。
- 交互：拖动平移、滚轮 / 双指缩放、双击复位；右下角放大 / 缩小 / 复位小按钮。轻点省份 = 选中（城市栏只显示该省城市，顶部出现「东京 ×」筛选签）；再点同一省或点空白 = 取消。
- 悬停（鼠标）显示小提示「省名 · N 座城市」。
- 载入中：地图区域内显示小法阵「正在描绘星图…」，不阻塞面板展开。

## 4. 城市栏
- 卡片：亮星 + 城市名 + 「省名 · N 段回忆」；点击 → `SB.scenes.go('city', {id}, {transition:'quill', x, y})`。
- 可编辑成员：卡片右侧小羽毛笔按钮 → 编辑城市对话框（改名 / 删除，沿用 v1.10 逻辑与确认文字）。
- 卡片排序：回忆多的在前，其次按创建时间。
- 空状态：「这里还没有我们的足迹」+ 引导文字（选中省份时：「东京还没有点亮的城市」）。
- 悬停卡片时地图上对应的星高亮（电脑）。

## 5. 添加城市
- 点击「添加城市」→ `SB.ui.dialog`：
  - 「所在地区」下拉（按名称排序；默认 = 当前选中的省份；无省级地图时隐藏）；
  - 「城市名」输入框（最多 30 字，Enter 提交）；
  - 「点亮」主按钮。
- 保存：`SB.store.addCity({country, countryName, region, regionName, name, lon, lat})`（经纬度取省份中心，与 v1.10 相同）；成功后提示「X 已点亮」、星星闪光、城市栏刷新并选中该省。
- 错误（重名、空名、网络）沿用 `SB.store.errText`。

## 6. 时空裂隙特效（Owner 选定）
### 展开（华丽档约 1.1 秒，柔和档约 0.8 秒）
1. **0–30%**：从点击处（限制在面板范围内）向上下长出一道极细的竖直光缝，光缝中心最亮（暖白），两侧淡蓝辉光。
2. **28–100%**：光缝向左右撕开，面板内容从缝里露出；两道裂缝边缘是发光的竖线，向面板两侧退去，退到边缘后淡出。
3. 面板背后：全屏深色幕布淡入（不透明度 ≤ 0.62），地球变暗留在后面，仍可隐约看到。
4. 内容分层浮现：头部（55%）→ 地图轮廓描边（62%，华丽档描边绘入，柔和档淡入）→ 城市栏与底部（85%）。
### 合拢（华丽档约 0.65 秒，柔和档约 0.45 秒）
- 逆序：左右合拢成一道光缝 → 光缝缩短消失于中心；幕布同时淡出。
### 稳定后
- 面板背景是缓慢流动的竖向极光光带（冷蓝为主，少量金色）+ 极少量上浮的星尘；地图区域上有一层中心更深的暗幕保证可读性。
- 华丽档：背景用 canvas 绘制，约 30fps，面板打开时才运行；页面隐藏 / 面板关闭立即停止。
- 柔和档 / 安卓：背景为 3 条 CSS 光带，只用 `transform` 做缓慢平移（合成器），没有 canvas。
### 实现约束
- 面板形状用 WAAPI `clip-path: inset()` 关键帧动画（两段：竖缝 → 撕开），不要每帧用 JS 写 `clip-path`。
- 裂缝边缘是两个独立的 DOM 元素（不被面板 clip 裁掉），只用 `transform`（`scaleY` / `translateX`）与 `opacity` 动画。
- 不使用 `filter: blur()` 作用在地球 WebGL 画布上（全屏滤镜在安卓上很贵）；用幕布变暗代替。
- 减少动态效果（`reduced`）：直接淡入淡出 200ms。
- 动画进行中再次点击 × / Esc：等展开完成后立刻合拢（不叠加）；在地球上快速双击不会打开两次。

## 7. 可访问性（WAI-ARIA APG Dialog Modal）
- 面板 `role="dialog"`、`aria-modal="true"`、`aria-labelledby` 指向国名标题。
- 打开后焦点移到关闭按钮（静态呈现时同样）；Tab / Shift+Tab 在面板内循环。
- Esc 关闭（菜单或对话框打开时不处理，交给它们）。
- 打开时地球场景其余内容（搜索、徽章、信息卡）设为 `inert`；关闭后恢复，焦点归还给打开前的元素（若仍在页面中）。

## 8. 验收
- 电脑 / 手机点击日本、中国、美国、冰岛（无省级地图）都能展开，地图完整显示在面板内，无溢出、无滚动条。
- 系统返回键 / 左上返回 / × / Esc / 点面板外均可关闭；关闭后地球停在该国家附近并短暂高亮。
- 面板 → 城市 → 返回：面板仍是展开状态（同一国家）；再返回 → 回到地球。
- 深链刷新：刷新时若历史状态为面板，直接呈现面板。
- 安卓：展开与合拢过程中没有闪烁；面板打开时地球不再持续重绘。

## 9. v1.11.1 · 手机抽屉下拉关闭 · 少量城市排版 · 静置降耗（复盘 #5 / #11）
> 参考：smooth_sheets `SwipeDismissSensitivity` 默认值（松手位移超过抽屉高度 30% 即关闭；向下甩动速度 ≥ 2 倍视口高度 / 秒即关闭）；抽屉无障碍做法（拖动只是附加手势，必须保留可见的关闭按钮）。

### 9.1 下拉关闭（仅手机抽屉布局 ≤ 720px）
- 抽屉顶部中央一条 36×4px 的把手（装饰，`aria-hidden`；关闭仍以 × 按钮为准）。
- 可拖动区域：把手 + 头部（国名区域）。地图区、城市栏、按钮上的按下不触发（地图拖动 / 横向滑动城市不受影响）。
- 跟手：只改面板 `transform: translateY(dy)`（dy ≥ 0，向上拖动阻尼为 0）；幕布不透明度随 dy 线性减弱。
- 松手判定：`dy > 面板高度 × 0.3` 或 `向下速度 ≥ 2 × innerHeight / 秒（且 dy > 24px）` → 关闭；否则 240ms 回弹。
- 关闭：从当前位移继续向下滑出（200ms，transform），然后走 `SB.scenes.back()` 的正常关闭链路，但**不再播放裂隙合拢**（已经滑走了）；历史、焦点、inert 恢复与其他关闭方式完全一致。
- 判定移动方向：移动超过 8px 时若水平分量更大 → 放弃拖动（交还给浏览器）。
- 遵守 v1.10.2 拖动稳定规则：`setPointerCapture`、window 级 `pointerup / pointercancel` 兜底、`lostpointercapture`、`blur`。
- 减少动态效果：仍可下拉关闭（跟手位移是用户直接操作），回弹 / 滑出时长 0。

### 9.2 城市少时的排版（手机）
- 城市 ≤ 2 座（含筛选后）时，城市栏改为纵向排列、卡片占满宽度；3 座及以上保持横向滑动。

### 9.3 静置降耗（复盘 #11）
- 华丽档极光背景：面板内 20 秒没有指针 / 键盘 / 滚动操作 → 降到约 10fps；任何操作立即恢复约 30fps。
- 地球：华丽档在面板完全展开后限制到约 30fps（柔和档 / 安卓仍完全跳过渲染）。

## v1.12.2 · 添加城市取真实位置、省份中文名（复盘 #3、#4）

### 问题
- 「添加城市」把城市放在**所在地区的中心**；大多数省级地图是投影坐标，没有经纬度可用，于是又退回**国家中心**——同一个国家的城市在地球上叠成一颗星（法国、德国、韩国、泰国……都是如此）。
- 中国、美国、日本以外的国家，地区名显示英文（Île-de-France、Gyeonggi）。

### 研究结论
- 省级地图（Highcharts map-collection 2.3.3）的分区带 `iso_3166_2` / `hasc` / `woe-id`。Unicode CLDR `subdivisions/zh.xml` 按 ISO 3166-2 提供分区中文名；Natural Earth admin-1（公有领域）提供 ISO / hasc / woe-id 对照、`name_zh` 与保证落在分区内部的 label point。部分条目是繁体或旧名，用 OpenCC 词典转简体，法国 2016 年大区手工修正。
- Open-Meteo Geocoding 支持 `countryCode`（ISO 3166-1 alpha-2）过滤；结果带 `admin1`（一级行政区，`language=zh` 时尽量中文）、`feature_code`、`population`。只发送城市名与国家代码。

### 数据（生成文件，不手改）
- 新块 `blocks/06-region-zh.html`（`tools/make_region_zh.py` 生成）：`SB.REGION_ZH[国家] = "短key=中文名,经度,纬度;..."`，先覆盖常去的 50 个国家；中国 / 美国 / 日本的中文名仍用 06-world-geo 手工表，只补代表点。
- `regionZh()`：手工表 → 生成表 → 英文原名。
- 地区中心：地图自带经纬度 → 生成表的代表点 → 国家中心（与以前相同的最后后备）。

### 添加城市对话框
1. 「所在地区」（多地区国家）+「城市名」不变；城市名下方新增**位置候选**（最多 6 条）：
   - 先显示本地结果（内置城市库 `SB.WORLD_CITIES` 中这个国家的城市；中国另查地级 / 县级行政区划，自带所在省份），再在 350ms 后补充 Open-Meteo 在线结果（`countryCode` 过滤、只取居民点 `PPL*`、按人口排序；6 秒超时；失败只显示一行小字，不影响保存）。
   - 每条显示：名称、所在地区（中文）、「本地 / 在线」不显示——用户只关心是不是这个地方。
2. 候选的所在地区：候选自带省份（中国行政区划）→ `admin1` 与地区中文名 / 英文名匹配（去掉省 / 州 / 府 / 县 / 道 / 都 / 市 / 区 / 郡等后缀）→ 离哪个地区代表点最近。
3. 名称完全相同的第一条候选**自动选中**（高亮 + 勾）；用户可以点另一条或「不指定位置」。选中候选时，「所在地区」自动切到候选所在的地区（用户之后仍可改）。
4. 保存：用候选的真实经纬度；没有选中候选时用地区中心，并提示「没有找到精确位置，已放在地区中心，之后可以在编辑里校准」。
5. 城市名仍是用户输入的文字（不被候选名替换）。

### 编辑城市对话框 · 校准位置
- 新增「位置」一行：「大致位置（地区中心）」或「已校准」，以及「校准位置」按钮；点开后出现与添加对话框相同的候选列表（预填城市名）。
- 校准使用**单独的地点搜索框**（预填城市名），这样城市名可以和地名不同（例如「京都站」）；本地城市库的结果借用同一地点在线结果的 `admin1` 判断地区。
- 添加对话框里，用户亲手改过「所在地区」后，只在这个地区里自动选候选；已选候选不在新地区时取消选择（放在新地区中心）。
- 保存时更新经纬度；候选在另一个地区时，同时更新 `region / regionName`（城市在面板里移到那个地区），并在候选下方说明。
- 判断「大致位置」：城市坐标与所在地区中心（或国家中心）相差小于 0.01°。

### 不变
- Store 接口不变（`addCity` / `updateCity` 只是多了真实的 `lon / lat`，旧城市不迁移）；面板布局、转场、`update` 钩子不变。

## 附录 · v1.10.2 及以前的国家地图场景（已在 v1.11.0 删除，仅供追溯）

### 块 09 · 国家地图与省份星星 提示词

#### 地图
- 按需加载该国的省级地图数据（显示旋转法阵和"正在描绘星图…"）。
- 用 SVG 绘制，铺满屏幕（四周留出标题和安全区）：
  - 省份为深夜蓝底，金色细边；去过的省份填充淡淡的金色光晕；
  - 悬停/点按的省份边线变亮、整块提亮；
  - 地图下方有一层模糊的金色投影，像漂浮在夜空里；
- 支持滚轮/双指缩放和拖拽平移（大国家如美国、俄罗斯很需要），双击复位。
- 标题：国名（大字）+ 统计「点亮 X/Y 个省份」。

#### 星星
- 每个省份中心一颗四芒星：
  - 去过：明亮金色，有光晕、缓慢脉动和偶尔的闪光；
  - 没去过：暗淡的灰金色小星，几乎不发光。
- 星星大小随地图缩放保持不变。

#### 悬浮窗
- 鼠标指向省份时（手机为点按），在旁边弹出卷轴风格的小窗：
  - 省份中文名（中国、美国、日本有中文名；其他国家显示原名）；
  - 去过的城市列表，每个城市前面一颗亮着的星星，点击城市名进入该城市的回忆目录；
  - 「＋ 添加城市」按钮：点开就地出现输入框，输入城市名回车即保存（星星立即点亮，带一次闪光动画）；
  - 每个城市右侧有一个小的编辑符号：可改名或删除。
- 鼠标从省份移到悬浮窗上时，窗口保持不消失；离开 0.4 秒后收起。

#### 返回（v1.8.0）
- 国家地图的父级是**世界星图**：左上角返回、菜单魔法路径、系统返回都直接回到地球（不再经过已删除的大洲国家目录页）。
- 回到地球时，地球自动转向刚才所在的国家并让它短暂高亮，用户能立刻看到自己从哪里回来。
