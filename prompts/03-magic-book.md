# 块 03 · 首页魔法书（质感升级版）提示词

## 构图
- 首页只有一本大魔法书，正对屏幕、居中、尽量撑满（桌面书高约视口 80%，手机宽约 92vw），比例 3:4。
- 默认微微转向（右侧和下侧露出厚厚的鎏金书页边），鼠标移动时随之倾斜（手机自动轻摆）。
- 书缓慢上下浮动；下方有托举的金色光晕和蜿蜒流动的金色能量线；背后有两层缓慢反向旋转的巨型法阵。
- 环绕光带（块 01）围着书公转，光点会从书前面经过再绕到书后面。

## 皮革质感
- 程序生成 512×512 皮革：多层噪声做出"荔枝纹"颗粒高度图，再按左上方光源计算明暗（浮雕光照），
  叠加细小划痕、毛孔和边缘磨损，颜色为深咖啡偏红。
- 封面四周压暗、中央被宝石照亮；整体有一层随倾斜移动的柔和反光（皮革油亮感）。

## 烫金工艺
- 所有金色图案（外框、角花、文字、法阵）做成"压印烫金"：
  - 下方一层暗色偏移阴影（像压进皮革里）；
  - 上方一层金属渐变（亮金 → 琥珀 → 暗铜）；
  - 最上面一层沿着图案流动的高光：一道斜向光带随鼠标倾斜扫过烫金部分（用图案本身做遮罩，只照亮金色）。
- 法阵外圈有一道光沿圆环缓慢绕行。

## 黄铜包角与书脊
- 封面四角各一块黄铜包角：金属渐变、铆钉、细刻花纹，边缘有高光。
- 书页边缘为鎏金：暖白纸页线 + 金色辉光。

## 中央机匣（核心视觉）
- 五层：刻度符文黄铜外环（120 秒一圈）、镂空齿轮环（逆向 60 秒）、三枚公转并自转的小齿轮、
  八芒星框（40 秒）、中心宝石。
- 宝石：多切面明亮式切工，琥珀金到暖白渐变；
  内部有缓慢旋转的折射光（锥形光芒）、四芒星闪光每隔几秒闪一下；周围光晕呼吸。
- 宝石后面有放射状的神光（锥形渐变，缓慢旋转）。
- 宝石就是开书按钮：靠近时光晕放大、机匣转速提升、出现提示「轻触宝石 · 开启星屿」。
  键盘可聚焦并用回车开启。

## v1.8.0 星辉层次（依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 5 节、8.2 节与 Owner 提供的「发光古书」参考图）

由远到近六层，所有层都围绕「宝石是光源」组织：

1. **星云底层**：两层缓慢漂移、反向旋转的暖金 / 深琥珀星云（大而柔的径向渐变 + 噪点纹理，屏幕混合），位于法阵后面；像真知晶球的外层云雾。
2. **宝石光溢 + 体积光**：书后方以宝石为源的一圈放射体积光（细长光束，极慢旋转，遮罩成圆形渐隐），以及投在背景上的暖色光斑；亮度跟随宝石呼吸，鼠标靠近宝石时变亮。
3. **3D 符文环**：一圈约 28 个发光拉丁 / 卢恩符文在书的腰部高度绕书公转（真正的 3D：转到书前面时在书前方、转到后面被书挡住），轻微上下起伏、闪烁；倾斜角与环绕光带一致。
4. **升腾烟雾与火星**（参考图）：书顶部缓慢升起数缕被宝石照成暖金色的烟（预渲染烟团精灵，边上升边旋转、拉长、淡出），夹带细小火星向上飘散；画在书所在层的专用画布上。
5. **书页边流光**：右侧与底部的鎏金书页边上，一道亮光沿书页边缘缓慢流动（与烫金流光同步但更慢）。
6. **金色能量细线**：底部原有的流动能量线增加两条从书底向两侧延伸、偶尔闪亮的细丝。

分档：low 档烟雾缕数减半、符文 16 个、星云静止旋转更慢；reduced 档全部静止（只保留静态光溢与星云）。所有新层 `pointer-events:none`，离开书场景时停止烟雾画布的 RAF。

开书时（块 04）：符文环加速并收向宝石、烟雾被吸入光柱、体积光变亮，与门钥匙转场衔接。

## v1.8.1「星夜摩洛哥皮」材质重设计（Owner：材质、质感、颜色、渲染重新设计）

> 依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 10.4 节（手工精装：摩洛哥山羊皮、盲压、烫金、dentelle 花边、金口、竹节书脊）。结构、交互、开书流程与 `SB.magicBook` 接口不变。

### 颜色与材质
- **皮革**：午夜靛蓝摩洛哥山羊皮。程序纹理保留荔枝纹法线光照，底色改为 `#1b2045`（R 27 G 32 B 69 左右），低频噪声做出中央略亮、四边磨光更深（`#0d1028`）的旧化斑驳；细划痕改为冷色。书背、书脊、内封同色系。
- **烫金**：香槟古金渐变 `#fbeec4 → #e0bf78 → #b08a3e → #6a4b1b`，比旧版橙金饱和度低；保留镜面高光滤镜，但外发光（glow）减半。
- **盲压**：在外框与内框之间新增一圈不上金的 dentelle 花边（小叶片 + 圆点 + 菱形，沿四边重复），用「压深」滤镜表现：内阴影（左上暗、右下亮的 1px 抛光边），颜色比皮革略深。法阵外圈再加一圈盲压圆点。
- **镶嵌星辰**：法阵八个顶点的小圆环中嵌入 8 颗「星辰蓝宝石」（小四芒星，冷白 → 浅蓝渐变，直径约 2.4% 书宽），各自以 5–9 秒周期轻轻闪烁（错开）。
- **包角**：古金雕花包角（香槟金渐变 + 深色雕刻线 + 一颗小蓝宝石铆钉），去掉橙铜色。
- **金口**：书页切口改为香槟金（降低外发光到旧版约 45%），流光保留但更柔。
- **宝石**：保留琥珀暖光（全书唯一暖光源），光晕亮度降低约 30%。

### 渲染
- 主光左上：封面叠加一层柔和的对角渐变（左上亮 6%、右下暗 18%）。
- 冷色轮廓光：封面右缘、下缘 1–2px 冷白高光（随倾斜轻微变化）。
- 环境光遮蔽：法阵外圈内侧与内框内侧一圈柔和暗影，让法阵看起来压进皮革。
- 皮革反光（`cv-gloss`）改为冷白、soft-light，随倾斜移动。
- 书下光晕从橙色改为淡金并减弱；背景氛围保持温暖书房色，但整体比书本更暗，让书成为视觉中心。

### 性能
- 纹理仍为一次生成（512² 皮革 / 256² 纸张）；新增的盲压、星辰都是静态 SVG，星辰闪烁用 CSS opacity 动画（reduced 关闭）。

## v1.8.2 手机性能与渲染稳定（Owner 真机反馈：魔法书页面一直闪烁、上方有一个很大很刺眼的光球、动态几乎看不到）

> 依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 第 11 节的定位结果。外观设计（星夜摩洛哥皮）不变。

- **光球**：根因是薄烟粒子用叠加混合（`lighter`）在书顶同一位置堆积。薄烟改为正常混合、单层 alpha ≤ 0.16，只在 high 档出现且最多 12 团；low 档不画薄烟。
- **对角切割与闪烁**：根因是 3D 符文环（`translate3d` 的 z 值穿过书本平面）进入了魔法书的 `preserve-3d` 上下文，手机 WebKit 会把相交平面切割并来回重排。符文环改为**2D 投影**：用倾斜椭圆 + 近大远小在平面上计算位置，正面的符文放在书前的图层（`#bk-runes-front`）、背面的放在书后的图层（`#bk-runes-back`），不再与书本发生 3D 相交。
- **low / 手机档**（`html:not([data-sb-perf="high"])`）：隐藏星云、体积光、折射、流光遮罩、薄烟、烫金辉光层、第二层法阵、书口流光、法阵流光环；皮革反光不用混合模式；能量脉络不做描线动画；背景法阵静止并缩小；烫金使用**廉价滤镜**（只有压印暗影，无镜面光照与模糊辉光）；小齿轮不做 SVG 属性旋转（会触发滤镜重绘）。
- **启动**：皮革 / 纸张程序纹理缓存到 localStorage（`sb-tex-leather-v182` / `sb-tex-paper-v182`），第二次打开不再生成。
- 开书星图：扉页内 `#bk-const`（见 `prompts/04-book-opening.md`）。
