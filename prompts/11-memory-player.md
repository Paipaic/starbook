# 块 11 · 「光影放映」多图编排放映 + 三种放映风格 + 四季主题（v1.7.0）提示词

> 依据：`docs/design/VISUAL_UPGRADE_PLAN.md` 第 6、7 节（v1.6.0 参数 + v1.7.0 调研与候选对比）。
> 范围：Magic Celestial Theme 的放映表现层 + `SB.audio`。读取 `SB.store` 现有回忆字段，以及**新增的可选字段 `style`**（见第 9 节）。不改存储结构、不改 schema_version。
> 保留 v1.6.0：放映厅、墨滴开场扉页、终章、控制条、`SB.audio`（含 duck）、照片等待 / 预加载、`SB.player` 调试接口。

## 1. 体验目标

放映不再是「一页一张」。每种风格是一位「导演」：它把这段回忆的照片编排成一条连续的时间线——画面里常常同时有两三张照片，**接力**更替：一张留着，另一张渐渐消失，新的一张在别处渐渐出现；画面永远不会「全部消失 → 空屏 → 全部出现」。照片节奏比 v1.6.0 快（每张焦点约 3.2–3.6 秒），只有描述较长时才多停留。字幕是画面设计的一部分：字号大、每种风格有自己的出现方式。

## 2. 引擎：声明式时间线

- 风格导演函数 `direct(slides, stage) → { items, marks, dur }`：
  - `items`：时间线元素。照片元素 `{kind:'photo', slide, i, t0, t1, keys:[{t, x, y, w, h, r, z}], kb:{s0,s1,x0,x1,y0,y1}, frame, enter:{type,dur,dir}, exit:{type,dur,dir}, depth}`；文字元素 `{kind:'text', text, t0, t1, box, look, vertical, enter, exit}`；装饰元素（星座连线、光尘、墨点等）。
  - 坐标单位是舞台宽高的比例（0–1），`keys` 之间正弦缓动插值，可以让一个面板从分屏位置**扩展成全画面**。
  - `marks`：每张照片成为焦点的时间，用于进度条、上一张 / 下一张、页码。
- 渲染器：每帧只根据时钟 T 计算每个元素的位置、透明度、遮罩、滤镜 → 暂停 = 停钟；跳转 = 设置 T；可任意 `seek`。
- DOM 按需：元素在 t0 前 1.5 秒创建（预加载、隐藏），t1 后移除；同屏最多约 6 个照片元素。
- 时间线只由（回忆内容、风格、舞台横竖）决定；横竖切换时重建时间线并保持当前进度比例。
- 下一张照片未就绪（签名地址 / 解码）时，时钟在它出现前 0.3 秒停住，显示「正在冲洗胶片…」。

## 3. 共用的转场库（照片元素的 enter / exit）

| 名称 | 效果 | 用在 |
|---|---|---|
| bloom 光晕显影 | 透明度 0→1、模糊 10px→0、亮度 1.5→1、缩放 1.05→1 | 星图、全幅溶解 |
| wipe 擦入 | clip-path 从一侧展开（左 / 右 / 上 / 下） | 分屏面板 |
| slit 光缝 | 从水平中线向上下张开，边缘一道金色光线 | 银幕全幅 |
| iris 虹膜 | 圆形从兴趣点扩大 | 银幕全幅 |
| blinds 百叶 | 竖条遮罩（12 条，柔边）逐渐填满 | 银幕全幅（每段最多一次） |
| bars 错位竖条 | 三联竖条错位上下滑入（Saul Bass《惊魂记》，放慢柔化） | 银幕三联 |
| expand 扩展 | 分屏中的一个面板扩大为全画面，另一面板滑出 | 银幕分屏 → 全幅 |
| drop 落下 | 从 1.3 倍、旋转 +8°、上方落到桌面，阴影由大变小，轻微回弹 | 手札 |
| stardust 化星尘 | 模糊、提亮、上浮、缩小、淡出，同时散出金色光尘 | 星图退场 |
| fade / drift | 淡出 / 沿方向漂移淡出 | 通用退场 |

接力规则：替换同一位置时，旧照片先开始退场，新照片延后 0.3–0.6 秒进场；整体转场 0.9–1.4 秒。

## 4. 风格一 · 银幕（cinema，默认）

电影蒙太奇：宽银幕黑边（横屏 1.85:1；竖屏 7% 画框）、胶片颗粒、暗角。

- **镜头组**（按照片横竖自动编排，结果固定）：
  - 全幅：横图（竖屏手机上是竖图）铺满，推 / 拉 / 横摇（竖屏上的横图做横摇，不硬裁）。
  - 双联：连续两张竖图并排；左面板从左擦入，0.45 秒后右面板从右擦入；若第三张也是竖图，则**左面板被替换**（旧图擦出、新图擦入），右面板不动；组的结尾，最后一张面板**扩展**为全画面，另一面板滑出。
  - 三联：连续三张竖图且描述都较短时，三条竖条错位上下滑入；结束时竖条交错滑出，露出下一个全幅镜头。
  - 竖屏手机：连续两张横图上下叠放（上从左、下从右擦入）。
- **全幅之间的转场**轮换：光晕溶解 → 光缝 → 虹膜 → 擦入 → 百叶 → …（同一种不连续出现）。
- **字幕**：思源宋体 600，暖白 + 柔和金色光晕：
  - 横屏全幅镜头上，单条 ≤ 12 字的短句使用**竖排大字**（右侧 8%，clamp(30px, 4.4vw, 56px)）。
  - 其他情况在下三分之一居中，clamp(24px, 3.4vw, 44px)（手机 22–26px），每行最多 14 字、两行、上短下长。
  - 出现：整句字距从 0.5em 收拢到 0.16em，同时逐字从模糊到清晰（每字 40ms）；下方一道细金线从中间向两侧展开。
  - 消失：整体上浮 6px、模糊、淡出 0.6s。

## 5. 风格二 · 星图（constellation）

星河拼贴：深夜星空，2–3 张烫金细框相片前后漂浮，金线把它们连成星座。

- **版式模板**（横屏 3 个、竖屏 3 个，循环使用）：每个模板定义 2–3 个相框位置（中心、可用宽高、倾斜、景深）和一个**文字区**；相框按照片原始比例完整显示（不裁切），大小受位置限制。
- **接力**：每 3.2 秒左右有一张新照片进入当前模板中「最老的」那个位置；该位置原来的照片先化星尘退场（1.2s），新照片在 0.5 秒后光晕显影进入。模板用完后，剩余照片错落退场，相机缓慢漂移到下一个模板。
- **视差**：整组相机缓慢漂移（≤ 1.5%）、轻微推近（1→1.03）；近景相框位移更大；每个相框有极轻的 3D 倾斜漂移（≤ 3°）。
- **星座线**：新照片出现时，从上一张照片中心画一条金色细线（描线动画 1.2s），旧照片退场时线一起淡出。
- **字幕**（editorial）：放在模板文字区，左对齐；先出现一个大号编号「03」（Cormorant Garamond，描金细线体），金线向右画出，然后每一行从遮罩下方升起（每行间隔 120ms），clamp(22px, 2.8vw, 38px)。消失时逐行下沉淡出。

## 6. 风格三 · 手札（journal）

魔法手札：烛光下的深色皮革书桌（只用渐变与颗粒，不画卡通道具），烛光轻微摇曳。

- **相片**：白边相纸（底边稍宽），落在桌面上，每张有固定的小角度（±7°）与真实阴影；每第三张角上一枚金色星形火漆贴。
- **编排**：相片沿一条之字形路径依次落下（横屏向右，竖屏向下）；**镜头沿桌面跟随最新的相片**，旧相片随镜头移动自然移出画面（同屏约 2–4 张）。
- **落下**：0.9 秒，从 1.3 倍、旋转 +8°、上方落下，阴影由远变近，轻微回弹；落下瞬间一圈极淡的金色微尘。
- **字幕**（墨迹手写）：写在相片旁边的桌面上，略带与相片相同方向的小倾斜；逐字**从左向右擦出**（每字 90ms，像被羽毛笔写出），刚写出的字更亮（湿墨金光），随后变成沉稳的金色；字有极小的随机基线偏移和旋转（±1.5°，固定不抖动）。文字留在桌面上，随镜头一起移走。clamp(24px, 3.2vw, 42px)。

## 6.5 四季主题（叠加在任意风格之上）

- 选项：按月份（默认，3–5 春、6–8 夏、9–11 秋、12–2 冬；无日期时为无）、无、春、夏、秋、冬。
- 组成：`pl-grade`（柔光叠色）+ `pl-tint`（季节光影渐变）+ 舞台滤镜（仅「完整」动效）+ `pl-season` 粒子画布；夏季额外有右上角缓慢旋转的阳光光束。
- 粒子（按画面面积缩放数量，「柔和」档 × 0.45，「减少动态效果」不画）：
  - 春：樱花瓣 7–14px，贝塞尔花瓣形 + 高光，自转并绕纵轴翻面，随风斜飘；
  - 夏：金色萤火，向上缓慢漂浮并明灭；
  - 秋：枫叶 9–19px，五裂叶形 + 叶脉，翻滚幅度大、下落更快，四种红橙色；
  - 冬：雪花三层（远小慢、中、近大而虚的散景）。
- 粒子只随放映时钟前进：暂停时一起停住。
- 放映中控制条增加季节按钮（显示当前季节图标），点开五个选项（无 / 春 / 夏 / 秋 / 冬），切换时旧粒子 1.2 秒淡出、新粒子淡入，调色 1.4 秒过渡；不保存。
- 放映厅的季节选项同理（只影响本次观看）；保存在编辑器里做（字段 `season`）。

## 7. 计时

- 扉页：3.6s + 标题与一段话字数 ÷ 7，最短 4.2s、最长 9s。
- 每张照片焦点时间：基础时间（银幕 3.4s、星图 3.2s、手札 3.6s）与「字幕阅读时间 + 0.6s」取大；字幕每秒 7 字、单条最短 2s。
- 终章 4s（预计时长只计 4s，终章画面停留直到用户操作）。
- 放映厅显示预计时长（随所选风格变化）。

## 8. 放映厅与控制

- 放映厅新增两行小选项：「STYLE」银幕 / 星图 / 手札，「SEASON」按月份 / 无 / 春 / 夏 / 秋 / 冬；默认选中这段回忆保存的值；在这里切换**只影响这一次观看**，不保存（保存在编辑器里做）。预计时长随风格更新。
- 控制条、键盘、滑动、进度条与 v1.6.0 相同；进度条每段对应一张照片（扉页一段）。上一张 / 下一张 = 跳到相邻照片的焦点时间，跳转时画面用 0.35s 的暗场衔接。
- 页码显示当前焦点照片序号。

## 9. 数据：回忆的 `style` / `season` 字段（新增，可选）

- `memories[id].style`：`'cinema' | 'constellation' | 'journal'`；缺省或未知值 → `'cinema'`。
- `memories[id].season`：`'auto' | 'none' | 'spring' | 'summer' | 'autumn' | 'winter'`；缺省或未知值 → `'auto'`（按回忆月份）。
- 这两个字段是 Magic Celestial Theme 的**表现偏好**，不是业务数据；其他 Theme 可以忽略。
- 旧回忆不需要任何迁移：没有该字段时按默认值放映；编辑并保存后才写入。
- 不改 `schema_version`，不需要 SQL。编辑器（块 12）负责写入；放映（块 11）只读。

## 10. 性能与无障碍

- 「完整」动效：全部效果。
- 「柔和」（low）：不使用模糊滤镜、不画胶片颗粒和光尘；星图同屏最多 2 张；保留位置运动与淡入淡出。
- 「减少动态效果」（reduced）：所有转场改为淡入淡出，不做镜头运动、视差、落下和倾斜。
- 只改 transform / opacity / filter / clip-path / mask；相片元素加 `contain: layout paint`。
- 照片 `alt` 使用描述或标题；字幕区域 `aria-live="polite"` 只播报当前字幕文字。

## 11. 不变的部分

- 开场：熄灯、墨滴入水、扉页逐字浮现（字号加大）。
- 终章：暖金闪白 → 「终 · FINIS」→ 再放一遍 / 返回相册，音乐渐弱到 30%。
- `SB.audio` 全站一个播放器、专属 > 全站 > 静音；放映厅不自动播放。
- `SB.player` 调试接口：`play / seek / jump / state`，新增 `setStyle / setSeason / stepSeason / estimate`；`state` 增加 `style`、`season`、`marks`、`items`。
- `SB.cinema`：风格与季节的公共定义（名称、说明、图标、`styleOf / seasonPref / resolveSeason`），供编辑器使用。
