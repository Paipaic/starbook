# 块 11 · 回忆放映与背景音乐 提示词

## 放映
- 全屏暗场，照片居中铺满（保持比例，四周用同一张照片的放大模糊版填满，避免留白）。
- 每张照片停留 6 秒，带缓慢的推拉平移（Ken Burns），切换时交叉淡化并有一阵金色光尘掠过。
- 文字：每张照片的描述在下方以逐字浮现的方式出现（标题字体，带柔光）；第一张前先显示回忆标题和日期的"扉页"。
- 控制条（停 3 秒自动隐藏，移动鼠标或点屏幕时出现）：上一张、播放/暂停、下一张、音乐开关、编辑、退出；
  底部有分段进度条。
- 手机：左右滑动切换，点一下显示/隐藏控制条。
- 键盘：← → 切换，空格暂停，Esc 退出。

## 背景音乐 `SB.audio`
- 全站一个音频播放器；切换曲目时 1.2 秒淡出淡入。
- 放映时优先播放该回忆的专属 BGM，否则播放全站 BGM；退出放映后恢复全站 BGM（如果之前在播放）。
- 浏览器要求用户点击后才能出声：第一次点击（如开书）后才开始播放。
- 菜单里的「背景音乐」可随时播放/暂停，显示当前曲名。
