# 块 11 · 「冥想盆放映厅」电影式回忆放映（v1.6.0）提示词

> 依据：`docs/design/VISUAL_UPGRADE_PLAN.md` 第 5、6 节。
> 范围：Magic Celestial Theme 的放映表现层 + `SB.audio`。只读取 `SB.store` 现有字段（title / date / note / cover / slides[{id,w,h,caption}] / bgm / bgmMode），不新增数据字段，不改存储。

## 1. 体验目标

像在冥想盆里看一段被保存的回忆：先在「放映厅」看到这段回忆的海报，按下「放映」后，灯光暗下、银幕框落下，一滴墨坠入水面，回忆从涟漪中浮现，照片一张张像电影镜头一样推进，字幕像电影字幕一样出现，最后以「终」字幕收尾。全程自动、流畅、不需要任何操作；想暂停或翻页时随时可以。

## 2. 结构（四幕）

### 第一幕 · 放映厅（进入场景时）
- 背景：封面照片放大、深度模糊、压暗，缓慢呼吸。
- 中央一张「海报」：封面照片放在烫金细框里（竖版 4:5 剪裁，手机宽 72vw），下方是日期（Cormorant 数字）、标题（思源宋体 600 + 金色烫金）、地点一行（国家 · 省份 · 城市，若存在）、照片张数与预计时长（如「6 张照片 · 约 1 分 20 秒」）。
- 海报下方一个大的圆形「放映」按钮：金色实心圆 + 外圈旋转的符文环（40 秒一圈），悬停时外圈光晕放大；按钮文字「放映」。
- 次要操作：编辑（有权限时）、返回。
- 若通过相册卡片上的「放映」直接进入（参数 `autoplay`），跳过这一幕直接开始第二幕。

### 第二幕 · 开场（约 4–6 秒）
1. **熄灯**（0.8s）：海报与放映厅淡出，背景压到全黑。
2. **银幕框落下**（1.0s，与熄灯重叠）：上下黑边从屏幕外滑入。横屏时可视区比例约 2.2:1；竖屏手机只加 7% 高度的上下黑边作为画框，不裁掉太多照片。
3. **墨滴入水**（Pensieve）：画面中心落下一点金色光，触水后泛起 3 圈涟漪（同心圆从 0 扩到 60vmin，透明度递减，依次延迟 0.25s）。
4. **扉页**：涟漪中浮现日期（小）→ 标题（大，逐字从模糊到清晰）→ 细金线从中间向两边展开 → 一段话（如有）。停留时间按阅读速度计算（见第 5 节）。
5. 音乐在按下「放映」时从 0 渐入（1.4s）。

### 第三幕 · 镜头（每张照片一个镜头）
每张照片自动选择镜头语言（按照片比例和序号，结果固定，不随机抖动）：

| 镜头 | 触发条件 | 运动 |
|---|---|---|
| 推镜 Push-in | 照片比例接近银幕 | 放大 1.00 → 1.10，同时向画面兴趣点（默认中上 45%）缓慢靠近 |
| 拉镜 Pull-out | 同上，与推镜交替 | 1.12 → 1.00 |
| 横摇 Pan | 照片比银幕宽得多（全景、竖屏手机上的横图） | 高度贴满，从一侧平移到另一侧 |
| 纵摇 Tilt | 照片比银幕窄得多且在竖屏 | 宽度贴满，从上往下缓慢移动 |
| 悬浮相片 Print | 竖图在横屏银幕上 | 照片以烫金相框悬浮在中央（不裁切），轻微 3D 转动（rotateY ±4°）和缓慢推近；背后是同一张照片的放大模糊版作为光场 |

- 所有运动使用平滑缓动（ease-in-out 正弦），不使用线性运动（线性会显得机械、卡顿）。
- 放大不超过 1.12：照片长边约 2400px，避免放大后发虚。
- 运动跨越整个镜头（包括进场与退场的重叠时间），切换时画面始终在动，不会出现“停住再切”的死板感。

### 镜头之间的转场（主要用溶解，节制使用特效）
- **光尘溶解**（默认，1.6s）：旧画面轻微柔化（模糊 0→8px）、提亮、淡出；新画面从模糊 6px 变清晰、从 1.04 倍落到原位；同时一阵金色光尘沿对角线掠过。
- **光漏**（每 4 个镜头一次，或最后一个镜头前）：溶解的同时，一道暖金色光从画面一侧扫过（滤色混合，柔和，不刺眼）。
- **墨滴揭幕**（第一张照片）：新照片从中心一个不规则的墨渍形状向外扩展显现，边缘柔软。
- 手动翻页时转场缩短为 0.8s。

### 字幕（参考 Netflix 简体中文字幕规范）
- 位置：银幕可视区底部居中，下方叠一层柔和的暗色渐变，保证任何照片上都清晰。
- 字体：思源宋体 400，字号 clamp(17px, 2.2vw, 24px)，暖白色，柔和阴影。
- 每行不超过 16 个汉字，最多两行；超过时按标点（，。！？；、）切分成多条依次出现的字幕；两行时上短下长（金字塔形）。
- 出现：逐字从模糊 + 下移 6px 到清晰（每字间隔 45ms）；消失：整体淡出 0.6s。
- 时长：每条字幕至少 1.8 秒，按每秒 7 字计算（比 Netflix 上限 9 字/秒更慢，适合抒情文字）。照片停留时间自动延长到字幕全部读完。

### 第四幕 · 终章
- 最后一个镜头后：暖金色「闪白」0.8s（dip to warm white）→ 黑场。
- 黑场中央：一枚小四芒星，下方「终」（思源宋体 900，金色），再下方「FINIS」（Cinzel，字距 .5em），以及日期和地点一行。
- 2 秒后出现两个按钮：「再放一遍」「返回相册」。音乐在 3 秒内渐弱到 30%，不突然停止。

## 3. 胶片质感
- 全程叠加极轻的胶片颗粒（预生成噪点纹理，平铺并按步进移动，透明度 0.06，叠加混合）。
- 四周暗角。
- 开场熄灯时有一次 0.3 秒的极轻微闪烁（放映机启动感），之后不再闪烁。

## 4. 控制
- 控制条（移动鼠标或点按屏幕时出现，2.5 秒无操作自动隐藏）：上一张、播放/暂停、下一张、音乐开关；右上角：编辑、退出。
- 底部进度：分段金线（扉页、每个镜头、终章），当前段实时增长；点击某段跳转。
- 手机：左右滑动切换镜头；点按切换控制条显示。
- 键盘：← → 切换，空格 暂停/继续，Esc 退出。
- 暂停时一切静止（镜头运动、字幕、转场都冻结），继续时从原处接着走。

## 5. 计时规则
- 扉页：3.6s + 标题与一段话的字数 ÷ 7 字/秒，最长 12s。
- 镜头：max(5.2s, 字幕总阅读时间 + 1.6s)，最长 14s。
- 预计时长 = 扉页 + 各镜头 + 终章 4s，显示在放映厅里。

## 6. 加载与流畅
- 照片地址来自 `SB.store.url(id)`（Private Storage 签名地址，可能稍后才可用）：最多等待 5 秒，期间显示「正在冲洗胶片…」。
- 每个镜头开始前预加载并解码后两张照片（`img.decode()`），避免切换时闪白。
- 动画由一个时钟驱动：所有运动、透明度、字幕都从时钟计算，暂停只是停止时钟。只改 transform / opacity / filter。
- 低性能档（动效「柔和」）：去掉模糊滤镜与胶片颗粒，只保留淡入淡出与镜头运动。减少动态效果：只做淡入淡出，不做镜头运动。

## 7. 相册入口（块 10）
- 每张回忆卡片右下角增加一个小的「放映」按钮（金色圆形播放图标）：直接进入第二幕开始放映。
- 点击卡片其他位置：进入放映厅（第一幕）。

## 8. 背景音乐 `SB.audio`
- 保留全站一个播放器、切换淡入淡出、专属 > 全站 > 静音的规则。
- 新增 `SB.audio.duck(level, ms)`：把音量平滑压到指定比例（终章使用），`SB.audio.duck(1)` 恢复。
- 放映厅（第一幕）不自动播放音乐；按下「放映」后才渐入。
