# 块 07 · 3D 世界星图地球仪 提示词（v1.8.0：星辉层次 + 搜索栏 + 导航精简）

> 依据：`docs/design/VISUAL_UPGRADE_PLAN.md` 第 5 节、8.2 / 8.4 节；性能遵守 `prompts/performance/02-book-to-globe.md`、`03-globe-to-country.md` 与 `docs/PERFORMANCE_GUIDE.md`。

## 场景
- 深靛蓝夜空，远处有缓慢闪烁的星海；地球位于画面中央（因顶部搜索栏，整体略下移约 3% 视口高），直径约为短边的 68%。
- 进入时：地球从远处飞近（相机距离 14 → base，2.4 秒缓出），粒子从 warp 恢复平静。
- 从国家地图返回时：地球自动转向刚才的国家并让它短暂脉动高亮。

## 地球本体（Three.js）
- 海洋：深靛蓝到夜蓝，带细密的经纬网格金线（极淡）。
- 陆地：国家轮廓绘制在画布纹理上的「星光地图」：暗金棕陆地、发光金色海岸线与国界；去过的国家整片琥珀金并外发光；悬停国家整体提亮、所在大洲微亮。
- 晨昏光与菲涅尔边缘光（金 + 冰蓝）。
- 城市星光：每个去过的城市一颗会脉动的金色星芒精灵。

## v1.8.0 星辉层次（真知晶球「一层又一层」）
由内到外：
1. **海面星辉高光**：只在海面上（不在陆地）根据光源方向做一块柔和的高光，随地球转动滑过海面，让球体更有体积。
2. **云雾层**：略大于地球（r = 1.012）的透明球，贴一张程序生成的柔和云丝纹理（暖白 / 淡金，低不透明度、叠加混合），以比地球慢的速度自转——地球表面「活着」。
3. **足迹光弧**：把我们点亮的城市按创建时间连成大圆弧，弧线略高出地表、两端贴地；一束光点沿弧线循环流动（金色 → 暖白），像一路走来的轨迹。城市少于 2 个时不显示。
4. **双层大气**：原菲涅尔大气（内层）+ 外层更大更淡的光晕精灵在地球后方缓慢呼吸。
5. **星盘环**：一圈倾斜的扁平光环（刻度 + 拉丁铭文 ORBIS · TERRARUM · MEMORIA · STELLARUM），极淡、加法混合，绕地球缓慢反向旋转，与两条光尘带形成交错的层次。
6. **星座线**：背景星海里若干组由极淡金线连接的星座，随相机轻微视差。
- 分档：low 档云雾纹理分辨率减半、星座线减少、光弧光点减少；reduced 档所有层静止只保留云雾与大气。

## 交互
- 拖拽 / 滑动旋转（惯性）；滚轮 / 双指缩放；闲置 4 秒后自动缓慢自转。
- 悬停陆地：浮动标签「国家中文名 · 大洲 · N 座城市」；悬停 180ms 后预取国家地图。
- 点击国家：幻影显形 portal 进入该国地图；点击南极洲：进入 `country:aq`。
- **大洲徽章**：七大洲的发光符文徽章跟随地球旋转；点击后地球**转向该大洲中心**（不再进入已删除的大洲国家目录页）。手机底部的大洲按钮同理。

## v1.8.0 搜索栏（地球正上方）
- 位置：标题「世界星图」下方、统计文字上方，宽 min(520px, 100vw − 32px) 的金边玻璃胶囊输入框，左侧符文放大镜，右侧清除按钮；占位文字「搜索城市或国家 · 例如 京都、冰岛、Paris」。手机标题缩小，搜索栏宽度占满。
- 结果面板（输入即出，最多 8 + 8 条），分组：
  1. **我们的足迹**：已点亮的城市（金星图标，显示「国家 · 省份」）；
  2. **国家与地区**：中文 / 英文名匹配，已点亮的显示「已点亮 · N 座城市」；
  3. **城市**：内置城市库即时结果 + 在线结果（Open-Meteo Geocoding，中文，输入停顿 350ms 后请求，缓存；加载时显示一行「正在星图中寻找…」；失败时显示「在线城市搜索暂时不可用，已显示本地结果」）。
  - 匹配排序：完全相同 > 前缀 > 包含；人口多的城市靠前；同名同国家去重。
  - 匹配文字金色高亮；键盘 ↑ ↓ 选择、Enter 确认、Esc 关闭；点空白处关闭。
  - 底部一行极小字「城市数据：GeoNames · Open-Meteo」。
- 选中后：
  - 地球用 easeInOutCubic 在 0.9–1.6 秒内（按角距离）沿最短方向转到目标经纬度，并推近到 0.8 倍距离；期间暂停自转；
  - 目标国家脉动高亮（比悬停更亮的金色）；目标点亮起星标 + 两圈扩散光环（城市），国家中心两圈更大的光环（国家）；
  - 屏幕下方浮出信息卡：名称、「国家 · 省份」、按钮「进入 X 地图」（有该国家时）与「打开我们的回忆」（是我们的城市时）、「×」。
  - 拖动地球或关闭卡片时退出聚焦状态。

## 性能
- 3D 引擎按需加载；像素比上限 1.75（low 1.25）；离开场景停止渲染；
- 纹理只在数据变化时重绘；新增层全部为一次生成的静态几何 / 纹理，每帧只更新 uniform 与少量变换。
- 在线搜索只在用户输入时请求，单次最多 10 条结果，带超时与取消。
