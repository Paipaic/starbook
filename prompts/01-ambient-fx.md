# 块 01 · 高级粒子特效 提示词

## 目标
让整个网站看起来像漂浮在魔法空气里：有景深、有呼吸、有光的流动，而且永远流畅不卡顿。

## 两块画布
- 背景画布（在场景下面）：远景和中景粒子、环绕光带的后半圈。
- 前景画布（在场景上面，鼠标可穿透）：近景火星、星芒、环绕光带的前半圈、鼠标魔法轨迹。
  这样粒子能真正"绕到书的前面再转到后面"。

## 粒子种类
1. 远景散景：大而虚的暖光圆斑，极慢漂移，随鼠标做反向视差（最大 18px）。
2. 中景金尘：细小光点，呼吸闪烁，缓慢上升并左右摇曳，视差 8px。
3. 近景火星：更亮更小，带 6~10 帧的渐隐拖尾，上升 10~24px/秒。
4. 星芒：十字四芒星，缓慢旋转，出现 → 闪亮 → 消失，每次只有少量同时存在。
5. 环绕光带：围绕当前焦点（魔法书或地球）的一条倾斜椭圆轨道，
   上百颗金色光点沿轨道缓慢公转，离观察者近的半圈画在前景、远的半圈画在背景并变暗变小。
6. 鼠标魔法轨迹：鼠标移动时洒下少量细碎金粉，1 秒内飘落消散（手机触摸时同样有）。
7. 神光：画面上方两三束斜向的柔光（CSS 渐变），缓慢明暗呼吸。

## 模式（平滑插值，绝不突变）
- `calm`：默认。
- `gather(x, y)`：所有粒子以旋涡形式向某点汇聚（开书、转场用）。
- `burst()`：短暂向外爆散。
- `warp()`：粒子拉成放射状光线向外飞（进入地球时的"穿越"感）。
- `orbit({x, y, rx, ry, tilt, count})`：设置/关闭环绕光带。
- `palette('warm' | 'night')`：书的世界用暖金，星图世界用金 + 冰蓝白。

## 性能
- 精灵图预渲染；只用 drawImage 和 globalCompositeOperation='lighter'。
- 数量：华丽档约 220、柔和档约 110、减少动态档约 30；设备像素比上限 2。
- 页面不可见时暂停；窗口改变尺寸时重新分布。

## v1.8.1 柔光规则
- gather（汇聚）：粒子与汇聚点距离 d < 160px 时 alpha 乘以 smoothstep(40, 160, d)；环绕光带在汇聚时同样淡出，避免叠加成白斑。
- warp（穿越）：放射线 alpha ≤ 0.35，屏幕中心 120px 内不画线。
- burst：只加速粒子，不提高亮度。
