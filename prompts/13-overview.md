# 块 13 ·「时光长卷」时间轴 提示词（v1.8.1，取代「回忆总览」）

> v1.8.1 Owner：「回忆总览」名字要更优美；页面太空旷，要呈现一条时光轴，按时间线把添加过的记录都呈现出来，可用鼠标控制滑动，并有动态效果；电脑与手机都要兼容。依据 `docs/design/VISUAL_UPGRADE_PLAN.md` 10.6 节。

## 命名
- 菜单与页面标题：**时光长卷**；拉丁铭文 **VOLUMEN TEMPORIS**；副标题「N 段回忆 · M 座城市 · 从 YYYY 年 X 月到 YYYY 年 Y 月」。

## 版式（全屏横向长卷，不再纵向滚动）
- 页眉（上 18%）：铭文、标题（思源宋体 900，clamp(30px,5vw,50px)，金色）、副标题。
- 中部：**时光河** —— 横贯画面的金色细线（1.5px，带 10px 柔光），线上有缓慢流动的光点（CSS 渐变位移动画，向右流动，周期 9s）。河上方 / 下方交替挂着回忆卡片，卡片与河之间用细金线（茎）连接到河上的星形节点。
- 背景：每个年份一个巨大的描边年份数字（Cormorant 数字，高度约 30vh，金色描边 alpha 0.12），以 0.45 倍速度视差移动；月份在河上用小刻度 + 「11 月」小字标注（同一月份只标一次）。
- **相片卡**：宽度按可用高度计算（电脑约 150–240px，手机 ≤ 56vw）；4:5 相框（封面图 object-fit:cover，金色细框 + 双层外框）；为了让上下两排卡片在一屏内完整显示，日期（Cormorant 数字，金色小字）与标题（最多两行）以底部渐暗字幕的形式压在相片下部；左上角城市胶囊（可点，进入城市）。无封面时显示深色手稿占位（星屿压印）。
- **景深**：根据卡片中心与屏幕中心的距离 d（以屏宽归一化），scale = 1 − 0.14·min(1, |d|)，opacity = 1 − 0.45·min(1, |d|)，并有极轻的 rotateY(±8°) 朝向中心；离中心最近的卡片节点星闪烁更亮，河上对应位置有一圈光晕。
- **年轮刻度条**（底部 10%）：一条细线，按时间比例标出所有年份与每段回忆的小点；一个半透明金色框表示当前可见范围；点击任意位置跳转（缓动 700ms）；拖动框可滚动。

## 交互
- 鼠标按住拖动（指针捕获；拖动距离 > 6px 时不触发卡片点击）；松开后惯性滑动（每帧速度 × 0.92，速度 < 0.05 停止）；两端有弹性阻尼（超出最多 80px，松开回弹）。
- 滚轮：纵向滚轮转换为横向移动；触控板横向滑动直接使用。
- 触控：手指横向滑动同鼠标；纵向手势不拦截（页面本身不滚动，但不影响系统手势）。
- 键盘：← → 跳到上一段 / 下一段回忆并居中；Home / End 跳到最早 / 最新。
- 点击卡片：用「冥想盆」转场进入该回忆的放映厅；点击城市名：「墨金书页」进入城市。
- 入场：时光河从左到右描出（900ms），卡片依次从河面升起（每张错开 70ms，最多 12 张有动画），默认停在**最新**的回忆附近（让最近的记忆先被看到），可向左回溯。

## 空状态
- 时光河仍然绘制但很淡；中央一句「时光长卷还是空白 · 从世界星图点亮第一座城市，写下第一段回忆吧」+ 金色按钮「前往世界星图」。

## 手机（≤ 760px）
- 页眉缩小到上 16%；卡片宽 56vw（最大 230px），上下交替但离河更近；年份数字高度 22vh；年轮刻度条保留并加大触控高度（≥ 36px）。
- 横向滑动；标题与刻度条不随卡片移动。

## 性能与无障碍
- 只在拖动 / 惯性 / 跳转动画期间运行 RAF；静止时不重绘。卡片只改 transform / opacity；封面 `loading="lazy"`，使用已签名 URL（必要时 `SB.store.prefetchUrls`）。
- reduced：无惯性与视差、无入场动画，跳转直接定位。
- 长卷容器 `role="list"`，卡片 `role="listitem"` 内为按钮；键盘焦点移动时自动滚动到可见。

## v1.10.0 · 「时光之环」——三维环形时光轴 + 悬挂卡片 + 周年节点
> Owner（2026-10-29）：把直线时光轴改成三维立体的环；环垂直于页面向纵深展开，不闭合，起点端和终点端很近、都在页面右侧，终点端有一条额外的线延伸出去（故事还没完）；保留滑动并适配；每条记录改为**悬挂在轴上的 3D 卡片**、缓慢转动；以第一条记录的日期为起点，每过一年加一个**时间节点**，节点上有 **ANNIVERSARY · 时光剪影** 按钮，放映上一节点到这一节点之间的全部记录（新风格，见 `prompts/14-year-reel.md`）。

### 1. 几何（自己做 3D 投影，不用共享的 preserve-3d 场景）
- 环是水平面上的一个圆（世界坐标 X 右、Y 上、Z 朝向观众），相机略微俯视（桌面 18°、手机 22°），透视投影后成为向纵深展开的椭圆。
- 所有「站点」（节点 + 记录）按时间顺序等角排列在 `2π − 缺口` 的圆弧上（缺口约 38°）。
- **焦点位置**在环的前方略偏右（θ = +18°）；滑动 = 绕竖直轴转动整环，让当前站点转到焦点位置。进入页面时停在最新的站点：此时终点在前方偏右、起点紧挨在它右侧，两端都在页面右侧。
- **延伸线**：从终点沿环的方向继续，但半径逐渐增大（1 → 2.3 倍）、同时向上扬起，从起点外侧飞出画面右上方（避开环下悬挂的卡片与铭牌）；线上有向外流动的光点，末端有一行小字「TO BE CONTINUED · 未完待续」。
- 环线与延伸线画在两层 canvas 上：环的后半圈在所有卡片之后，前半圈在后排卡片之前、前排卡片之后（保证遮挡关系正确）。线宽、亮度随纵深变化，前粗亮后细暗；环上有缓慢流动的金色光点。

### 2. 悬挂卡片
- 每条记录是一枚从站点垂下的卡片：一根细金线（长约卡宽 0.35）+ 4:5 的立体卡片（正面封面 + 日期 + 标题；背面深色金箔纹样 + 标题、日期、城市、照片数）。
- 卡片有自己的透视（每张卡片独立的 3D 上下文，正反两面平行贴合，不与其他平面相交），**缓慢自转**（约 24 秒一圈，每张相位不同）；转到焦点位置或鼠标悬停时平滑转回正面并停住；整根线 + 卡片像钟摆一样极轻地摆动（±1.6°）。
- 景深：越靠后越小、越暗（透明度 1 → 0.35），层级按纵深排序；后排卡片不可点击（避免误触），前半圈可点击打开放映（保持 `from:'overview'`）。城市标签可点击进入城市。
- 卡片大小：焦点处卡宽 = 桌面 min(220px, 17vw)，手机 42vw；记录很多（站点间距过小）时卡片按比例缩小（不低于 0.6 倍）。

### 3. 时间节点
- 起点节点 = 第一条有日期的记录所在月份（「INITIUM · 起点」）。之后每满 12 个月一个周年节点（「ANNIVERSARIUM · I / II …」，日期 YYYY · MM），只生成不晚于本月的节点。
- 最后一个周年节点之后如果还有记录，在末尾加一个「此刻」节点（「第 N 年 · 至今」）。
- 节点在环上是一枚更大的发光星环；下方悬挂一块小铭牌：拉丁名、日期、该年的记录数，以及按钮 **ANNIVERSARY · 时光剪影**（起点节点没有按钮）。按钮放映「上一节点（含）到这一节点（不含）」之间的记录；「此刻」节点放映最后一个周年节点以来的记录。
- 背景正中有一枚巨大的描边年份数字，随焦点站点的年份淡入淡出（视差）。

### 4. 交互（与 v1.8.1 一致的手感）
- 拖动 / 滚轮 / ← → / Home / End：转动环；有惯性与两端回弹；点按卡片打开放映、点城市标签进城市、点节点按钮放映时光剪影。
- 底部年轮刻度条保留：点 / 拖跳到最接近该时间的站点；高亮当前焦点。
- 静止档（reduced）：不自转、不摆动、无流动光点；柔和档 30fps。
- 页面隐藏或离开场景时停止动画循环。
