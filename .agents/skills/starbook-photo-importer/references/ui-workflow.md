# 网页操作与控件（本地源码 v1.9.2）

依据 `blocks/07-globe.html`、`09-country-map.html`、`10-city-album.html`、`12-memory-editor.html` 和 `05-store.html`。2026-10-28 在线核对了开书、城市搜索、中国省份地图及添加城市表单，并用上海一段真实回忆验证三张照片上传、单张描述、封面、两张编组、组描述、保存和重开。城市创建及上传失败处理尚未端到端验证。网站更新后应重新检查；下列控件只在对应场景和权限下出现，不保证始终存在。以当前可见控件与状态为准。

## 进入地点

1. 打开 https://paipaic.github.io/starbook/。未登录时页面为「星屿之书登录」，有「邮箱」「密码」「开启星屿」。优先使用已有登录会话；若未登录且用户已配置项目根目录 `.starbook-login.local.json`，可读取其中 `email`、`password` 用于该站正常登录。只在适用的计算机操作工具支持安全输入、不会向用户可见的命令、日志、聊天、清单或截图输出密码时使用；不要在命令参数中嵌入密码。配置不存在、为空、无法安全输入或登录失败时请用户自行登录，不能猜测、输出或反复尝试密码。不得将配置文件上传、提交或复制到成果中。确认账户中的「当前的书」和编辑者身份。
2. 进入「世界星图」；搜索框无障碍名称「搜索城市或国家」。搜索城市或国家，选择匹配的搜索结果及其国家、省州说明。定位结果卡有「打开我们的回忆」（已有城市匹配时）或「进入中国地图」等「进入{国家}地图」。直接打开已有城市时，仍需核对同名城市所在省州，不能仅凭城市名。
3. 在国家地图选择正确省州（地图元素与其省份标记；`#cm-pop` 的无障碍名称「省份城市」）。选择已有城市名可进入城市；若不存在，在该省份弹窗中点「添加城市」，在「城市名」输入后点「点亮」。省州不能靠名字猜；城市创建会写入真实数据。地图位置由该省州中心估计，不是精确城市坐标。
4. 城市页有回忆时，点「新的回忆」或页面底部「写下第 … 章」；没有回忆时，点「写下第一章」或「添加第一段回忆」。已有回忆卡的「编辑：{标题}」打开原记录；先核实归属，避免误改或重复。

## 编辑一段回忆

1. 对话框「新的回忆／编辑回忆」的故事区域：标题输入框上限 40 UTF-16 代码单元；「年份」「月份」分别为 select，年份范围 2000 至当前年加一，日期只保存年月；「一段话」上限 300 UTF-16 代码单元。复制源文案前检查长度，避免浏览器静默截断。
2. 影像区域有「批量添加」，对应多文件输入 `aria-label="批量选择照片"`；空白添加卡「添加照片」的输入 `aria-label="选择照片"` 也支持多文件。仅选择待上传照片，按清单顺序添加；等待「正在上传」完成，核对数量和照片与顺序。上传队列最多两个并发；每张处理及上传结束前不能保存。失败面板显示「重试」「忽略」；核对失败对象再处理，不因失败而默默丢照片。
3. 每张卡片有 `aria-label="第 N 张照片的描述"`，最多 120 UTF-16 代码单元；照片按钮「设为封面」「前移」「后移」「移除」。按照片实际画面核对卡片顺序，填各自描述，再设置封面。上传完成顺序可能不同，但代码先按所选文件顺序占位；仍应验证。
4. 点「选择」，勾选每张卡的 `选择第 N 张照片`；选中至少两张无共同分组照片后出现「编为一组」。点击后照片被聚集，出现 `第 N 组照片` 和 `第 N 组照片的共同描述`；组描述上限 300 UTF-16 代码单元。组号和照片序号会变化，重新读取页面后再继续。涉及已有组时动作变成「加入这一组」或「合并为一组」，可能包含原组全部成员；先核实避免误合并。组内单张描述隐藏但保留；组描述为空时按单张描述放映。每次操作后校验组成员和顺序。
5. 选择模式的「全选」「反选」「取消选择」「完成」分别影响选中状态；「完成」退出并清除选择。组提供「整组前移」「整组后移」「拆组」。单张前移/后移在组边缘可能变成「移出这一组」；拖放也可改变分组，谨慎核对。未经要求不要操作「删除这段回忆」。
6. 根据 [创作与设置 prompt](creative-prompt.md) 和清单选择「放映风格」和「乐章」；「季节主题」目前统一选「按月份」，用户后续明确指定优先；确保 radio 的选中状态正确。点「保存」前检查标题非空、至少一张照片、全部上传成功；完成后应看到「回忆已收进星屿之书」。再次打开该回忆的「编辑：{标题}」，核对字段、照片数量、组、风格、季节和音乐，确认保存后再进入下一事件。上传失败、保存结果不明、权限或冲突错误时先检查现状，再决定是否重试；不要使用整本书覆盖方式。

## 项目接口边界

网页通过 `SB.store.addCity`、`SB.store.uploadImage`、`SB.store.saveMemory` 实现上述 UI，保存使用 revision 检测、现有认证及 RLS。它们不是经过本任务验证的稳定批量导入 API；不得把浏览器内部函数当成已验证的自动上传接口。文件上传需要当前环境真实支持文件选择，不能假设每个浏览器控制工具都支持。`references/starbook.md` 记录数据映射。
